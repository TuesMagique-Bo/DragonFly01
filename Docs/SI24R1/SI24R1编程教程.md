## 1. SI24R1 简介

SI24R1 是南京中科微电子推出的 **2.4GHz 无线收发芯片**，完全兼容 nRF24L01+ 协议，是飞控遥控器通信的理想选择。

**核心特性：**

| 特性 | 参数 |
|------|------|
| 工作频段 | 2.400 - 2.525 GHz，126 个频道 |
| 通信接口 | 4 线 SPI（最高 10MHz） |
| 数据速率 | 250kbps / 1Mbps / 2Mbps |
| 发射功率 | 0dBm / -6dBm / -12dBm / -18dBm（可调） |
| 最大功率 | +7dBm（比 nRF24L01+ 高） |
| 接收灵敏度 | -83dBm @ 2Mbps |
| 工作电压 | 1.9 - 3.6V |
| 发射电流 | ~12mA @ 0dBm |
| 接收电流 | ~13.5mA |
| 待机电流 | ~26μA |
| 数据包 | 1-32 字节，支持 Enhanced ShockBurst |
| 多通道 | 6 个接收通道（Pipe） |
| 自动应答 | 硬件自动 ACK |
| 自动重传 | 可配置次数和间隔 |

**与 nRF24L01+ 的对比：**

| 特性 | SI24R1 | nRF24L01+ |
|------|--------|-----------|
| 最大发射功率 | +7dBm | 0dBm |
| 通信距离 | 更远 | 标准 |
| 寄存器兼容 | 完全兼容 | - |
| 价格 | 更低 | 较高 |

## 2. 硬件连接

### 2.1 引脚连接

STM32F411CEU6 与 SI24R1 通过 SPI 接口连接，共需 **6 个引脚**（含可选 IRQ）：

```
STM32F411CEU6           SI24R1
─────────────────────────────────────
PB13 (SPI2_SCK)  ────── Pin 3 (SCK)
PB14 (SPI2_MISO) ────── Pin 4 (MISO)
PB15 (SPI2_MOSI) ────── Pin 5 (MOSI)
PB12 (GPIO)      ────── Pin 1 (CSN)   ← 片选，软件控制
PA4  (GPIO)      ────── Pin 2 (CE)    ← 芯片使能，控制收发模式
PA3  (GPIO)      ────── Pin 8 (IRQ)   ← 可选中断引脚
```

> **注意：** 以上为典型连接，请以实际原理图为准。CSN 和 CE 引脚可选用任意 GPIO。

### 2.2 SPI 模式

SI24R1 的 SPI 时序要求：

| 参数 | 要求 |
|------|------|
| **CPOL** | 0（SCK 空闲低电平） |
| **CPHA** | 0（第一个时钟沿采样） |
| **最大时钟** | 10 MHz |
| **数据位宽** | 8 bit |
| **数据方向** | MSB First |

### 2.3 CSN 和 CE 的控制逻辑

| CSN | CE | 状态 |
|-----|-----|------|
| 0 | x | SPI 通信使能 |
| 1 | 0 | 待机模式（Standby-I） |
| 1 | 1 | 收发模式（TX/RX 取决于寄存器配置） |

## 3. SPI 通信基础

### 3.1 SPI 命令格式

所有 SPI 通信都遵循以下格式：

```
第 1 字节：命令字（含 R/W 位 + 寄存器地址）
第 2+ 字节：数据
```

**命令字格式：**

```
Bit 7    Bit 6-0
  │        │
  │        └── 寄存器地址（5 bit，0x00 - 0x1F）
  └── R/W: 0 = 写寄存器, 1 = 读寄存器
```

### 3.2 常用命令

| 命令名 | 命令字 | 功能 |
|--------|--------|------|
| R_REGISTER | 0x00 + 地址 | 读寄存器 |
| W_REGISTER | 0x20 + 地址 | 写寄存器 |
| R_RX_PAYLOAD | 0x61 | 读取接收 FIFO |
| W_TX_PAYLOAD | 0xA0 | 写入发送 FIFO |
| FLUSH_TX | 0xE1 | 清空发送 FIFO |
| FLUSH_RX | 0xE2 | 清空接收 FIFO |
| NOP | 0xFF | 空操作（常用于读状态寄存器） |

### 3.3 读写时序

**写寄存器（W_REGISTER + 地址 + 数据）：**

```
CSN = 0;                          // 选中器件
SPI_WriteByte(0x20 | reg_addr);   // 命令字：写寄存器
SPI_WriteByte(data);              // 写入数据
CSN = 1;                          // 释放器件
```

**读寄存器（R_REGISTER + 地址 → 读回数据）：**

```
CSN = 0;                          // 选中器件
SPI_WriteByte(0x00 | reg_addr);   // 命令字：读寄存器
data = SPI_ReadByte();            // 读取数据
CSN = 1;                          // 释放器件
```

## 4. 寄存器速查表

### 4.1 核心寄存器

| 地址 | 名称 | 功能 | 关键位 |
|------|------|------|--------|
| **0x00** | CONFIG | 配置寄存器 | [7]保留, [6]MASK_RX_DR, [5]MASK_TX_DS, [4]MASK_MAX_RT, [3]EN_CRC, [2]CRCO, [1]PWR_UP, [0]PRIM_RX |
| **0x01** | EN_AA | 自动应答使能 | 每 bit 对应一个 Pipe |
| **0x02** | EN_RXADDR | 接收通道使能 | 每 bit 对应一个 Pipe |
| **0x03** | SETUP_AW | 地址宽度 | [1:0] = 01(3字节)/10(4字节)/11(5字节) |
| **0x04** | SETUP_RETR | 自动重传 | [7:4]ARD=重传间隔, [3:0]ARC=重传次数 |
| **0x05** | RF_CH | 频道选择 | [6:0] = 0-125（2400MHz + 频道号） |
| **0x06** | RF_SETUP | 射频设置 | [7:5]保留, [4:3]功率, [2:1]速率, [0]LNA |
| **0x07** | STATUS | 状态寄存器 | [7]保留, [6]RX_DR, [5]TX_DS, [4]MAX_RT, [3:1]RX_P_NO, [0]TX_FULL |
| **0x08** | OBSERVE_TX | 发送观察 | [7:4]PLOS_CNT=丢包计数, [3:0]ARC_CNT=重传计数 |
| **0x09** | RPD | 载波检测 | [0]RPD=1 表示检测到信号 |
| **0x0A-0x0F** | RX_ADDR_P0-P5 | 接收通道地址 | 5 字节地址（Pipe 0 和 Pipe 1 可设全 5 字节） |
| **0x10** | TX_ADDR | 发送地址 | 5 字节，与 RX_ADDR_P0 保持一致 |
| **0x11-0x16** | RX_PW_P0-P5 | 各通道有效载荷宽度 | 1-32 字节 |
| **0x17** | FIFO_STATUS | FIFO 状态 | [7]保留, [6]TX_REUSE, [5]TX_FULL, [4]TX_EMPTY, [3:1]保留, [0]RX_FULL |
| **0x1C** | DYNPD | 动态负载使能 | 每 bit 对应一个 Pipe |
| **0x1D** | FEATURE | 特性使能 | [2]EN_DPL, [1]EN_ACK_PAY, [0]EN_DYN_ACK |

### 4.2 STATUS 寄存器详解

| 位 | 名称 | 含义 |
|----|------|------|
| 6 | RX_DR | 收到数据（写 1 清除） |
| 5 | TX_DS | 发送成功（写 1 清除） |
| 4 | MAX_RT | 达到最大重传次数（写 1 清除） |
| 3:1 | RX_P_NO | 收到数据来自哪个 Pipe（000-101 = Pipe 0-5，110-111 = 空） |
| 0 | TX_FULL | 发送 FIFO 已满 |

## 5. 初始化流程

### 5.1 CubeMX 配置 SPI

在 CubeMX 中配置 SPI2：

| 参数 | 设置值 |
|------|--------|
| **Mode** | Full-Duplex Master |
| **NSS** | Software（CSN 用 GPIO 软件控制） |
| **Data Size** | 8 bit |
| **CPOL** | Low |
| **CPHA** | 1 Edge |
| **Prescaler** | 8（84MHz / 8 = 10.5MHz，略高于 10MHz，如需保守可用 16） |
| **Baud Rate** | ~10.5 MBits/s |

CSN 和 CE 引脚设为 GPIO_Output（推挽输出，无上拉，高速）。

### 5.2 初始化代码

```c
/* 引脚定义（根据实际原理图修改） */
#define SI24R1_CSN_PORT     GPIOB
#define SI24R1_CSN_PIN      GPIO_PIN_12
#define SI24R1_CE_PORT      GPIOA
#define SI24R1_CE_PIN       GPIO_PIN_4
#define SI24R1_IRQ_PORT     GPIOA
#define SI24R1_IRQ_PIN      GPIO_PIN_3

/* 宏定义 */
#define SI24R1_CSN_LOW()    HAL_GPIO_WritePin(SI24R1_CSN_PORT, SI24R1_CSN_PIN, GPIO_PIN_RESET)
#define SI24R1_CSN_HIGH()   HAL_GPIO_WritePin(SI24R1_CSN_PORT, SI24R1_CSN_PIN, GPIO_PIN_SET)
#define SI24R1_CE_LOW()     HAL_GPIO_WritePin(SI24R1_CE_PORT, SI24R1_CE_PIN, GPIO_PIN_RESET)
#define SI24R1_CE_HIGH()    HAL_GPIO_WritePin(SI24R1_CE_PORT, SI24R1_CE_PIN, GPIO_PIN_SET)
#define SI24R1_IRQ_READ()   HAL_GPIO_ReadPin(SI24R1_IRQ_PORT, SI24R1_IRQ_PIN)

/* 寄存器命令 */
#define SI24R1_CMD_R_REGISTER        0x00
#define SI24R1_CMD_W_REGISTER        0x20
#define SI24R1_CMD_R_RX_PAYLOAD      0x61
#define SI24R1_CMD_W_TX_PAYLOAD      0xA0
#define SI24R1_CMD_FLUSH_TX          0xE1
#define SI24R1_CMD_FLUSH_RX          0xE2
#define SI24R1_CMD_NOP               0xFF

/* 寄存器地址 */
#define SI24R1_REG_CONFIG            0x00
#define SI24R1_REG_EN_AA             0x01
#define SI24R1_REG_EN_RXADDR         0x02
#define SI24R1_REG_SETUP_AW          0x03
#define SI24R1_REG_SETUP_RETR        0x04
#define SI24R1_REG_RF_CH             0x05
#define SI24R1_REG_RF_SETUP          0x06
#define SI24R1_REG_STATUS            0x07
#define SI24R1_REG_OBSERVE_TX        0x08
#define SI24R1_REG_RPD               0x09
#define SI24R1_REG_RX_ADDR_P0        0x0A
#define SI24R1_REG_RX_ADDR_P1        0x0B
#define SI24R1_REG_TX_ADDR           0x10
#define SI24R1_REG_RX_PW_P0          0x11
#define SI24R1_REG_FIFO_STATUS       0x17
#define SI24R1_REG_DYNPD             0x1C
#define SI24R1_REG_FEATURE           0x1D

/* 载荷宽度 */
#define SI24R1_PAYLOAD_WIDTH         32

/* 地址宽度 */
#define SI24R1_ADDR_WIDTH            5

/* 频道（2.400GHz + 频道号 MHz） */
#define SI24R1_RF_CHANNEL            40    /* 2.440GHz */

/* ───────────────── SPI 底层函数 ───────────────── */

static uint8_t SI24R1_SPI_ReadWriteByte(uint8_t tx_data)
{
    uint8_t rx_data;
    HAL_SPI_TransmitReceive(&hspi2, &tx_data, &rx_data, 1, 10);
    return rx_data;
}

/* ───────────────── 寄存器读写 ───────────────── */

uint8_t SI24R1_ReadReg(uint8_t reg)
{
    uint8_t value;
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_R_REGISTER | reg);
    value = SI24R1_SPI_ReadWriteByte(0xFF);
    SI24R1_CSN_HIGH();
    return value;
}

void SI24R1_WriteReg(uint8_t reg, uint8_t value)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_W_REGISTER | reg);
    SI24R1_SPI_ReadWriteByte(value);
    SI24R1_CSN_HIGH();
}

void SI24R1_ReadBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_R_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        buf[i] = SI24R1_SPI_ReadWriteByte(0xFF);
    }
    SI24R1_CSN_HIGH();
}

void SI24R1_WriteBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_W_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        SI24R1_SPI_ReadWriteByte(buf[i]);
    }
    SI24R1_CSN_HIGH();
}

uint8_t SI24R1_ReadStatus(void)
{
    uint8_t status;
    SI24R1_CSN_LOW();
    status = SI24R1_SPI_ReadWriteByte(SI24R1_CMD_NOP);
    SI24R1_CSN_HIGH();
    return status;
}

/* ───────────────── 初始化 ───────────────── */

uint8_t SI24R1_Init(void)
{
    uint8_t addr[SI24R1_ADDR_WIDTH] = {0x34, 0x43, 0x10, 0x10, 0x01};

    /* 1. 进入待机模式 */
    SI24R1_CE_LOW();

    /* 2. 设置地址宽度：5 字节 */
    SI24R1_WriteReg(SI24R1_REG_SETUP_AW, 0x03);  // 5 bytes

    /* 3. 设置自动重传：间隔 1000μs，最多重传 5 次 */
    SI24R1_WriteReg(SI24R1_REG_SETUP_RETR, (5 << 4) | 5);
    // ARD = 0101 (1000μs), ARC = 0101 (5 次)

    /* 4. 设置频道：2.440GHz */
    SI24R1_WriteReg(SI24R1_REG_RF_CH, SI24R1_RF_CHANNEL);

    /* 5. 设置射频参数：2Mbps, 0dBm, LNA 增益 */
    SI24R1_WriteReg(SI24R1_REG_RF_SETUP, (0 << 3) | (1 << 1) | (1 << 0));
    // 功率: 00=0dBm, 速率: 01=2Mbps, LNA: 1=高增益

    /* 6. 设置接收地址（Pipe 0） */
    SI24R1_WriteBuf(SI24R1_REG_RX_ADDR_P0, addr, SI24R1_ADDR_WIDTH);

    /* 7. 设置发送地址（与 Pipe 0 相同） */
    SI24R1_WriteBuf(SI24R1_REG_TX_ADDR, addr, SI24R1_ADDR_WIDTH);

    /* 8. 设置 Payload 宽度 */
    SI24R1_WriteReg(SI24R1_REG_RX_PW_P0, SI24R1_PAYLOAD_WIDTH);

    /* 9. 使能 Pipe 0 自动应答 */
    SI24R1_WriteReg(SI24R1_REG_EN_AA, 0x01);  // 只使能 Pipe 0

    /* 10. 使能接收通道 0 */
    SI24R1_WriteReg(SI24R1_REG_EN_RXADDR, 0x01);  // 只使能 Pipe 0

    /* 11. 使能动态 Payload 长度 */
    SI24R1_WriteReg(SI24R1_REG_DYNPD, 0x01);  // Pipe 0 动态长度
    SI24R1_WriteReg(SI24R1_REG_FEATURE, 0x04);  // EN_DPL=1

    /* 12. 上电，设为接收模式 */
    // CONFIG: 不上屏蔽中断, CRC 2字节, 上电, 接收模式
    SI24R1_WriteReg(SI24R1_REG_CONFIG, 0x0F);
    // MASK_RX_DR=0(不屏蔽), EN_CRC=1, CRCO=1(2字节), PWR_UP=1, PRIM_RX=1

    /* 13. 清空 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_FLUSH_TX);
    SI24R1_CSN_HIGH();
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_FLUSH_RX);
    SI24R1_CSN_HIGH();

    /* 14. 等待稳定 */
    HAL_Delay(2);

    /* 15. 使能接收 */
    SI24R1_CE_HIGH();

    /* 验证：读取 CONFIG 寄存器 */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    if (config != 0x0F) {
        printf("SI24R1 init failed! CONFIG=0x%02X\r\n", config);
        return 0;
    }

    printf("SI24R1 init OK\r\n");
    return 1;
}
```

## 6. 数据收发

### 6.1 发送数据

```c
uint8_t SI24R1_SendPacket(uint8_t *data, uint8_t len)
{
    uint8_t status;

    /* 限制长度 */
    if (len > SI24R1_PAYLOAD_WIDTH) {
        len = SI24R1_PAYLOAD_WIDTH;
    }

    /* 1. 切换到待机模式 */
    SI24R1_CE_LOW();

    /* 2. 切换到发送模式 */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    config &= ~0x01;  // PRIM_RX = 0（发送模式）
    SI24R1_WriteReg(SI24R1_REG_CONFIG, config);

    /* 3. 清空发送 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_FLUSH_TX);
    SI24R1_CSN_HIGH();

    /* 4. 写入数据到发送 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_W_TX_PAYLOAD);
    for (uint8_t i = 0; i < len; i++) {
        SI24R1_SPI_ReadWriteByte(data[i]);
    }
    SI24R1_CSN_HIGH();

    /* 5. 启动发送（CE 上升沿触发） */
    SI24R1_CE_HIGH();
    HAL_Delay(1);  // 至少保持 10μs
    SI24R1_CE_LOW();

    /* 6. 等待发送完成 */
    uint32_t timeout = 1000;  // 超时 1ms
    while (timeout--) {
        status = SI24R1_ReadStatus();
        if (status & 0x20) {  // TX_DS
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x20);  // 清除标志
            return 1;  // 发送成功
        }
        if (status & 0x10) {  // MAX_RT
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x10);  // 清除标志
            SI24R1_CSN_LOW();
            SI24R1_SPI_ReadWriteByte(SI24R1_CMD_FLUSH_TX);
            SI24R1_CSN_HIGH();
            return 0;  // 达到最大重传次数
        }
    }

    return 0;  // 超时
}
```

### 6.2 接收数据

```c
uint8_t SI24R1_ReceivePacket(uint8_t *data, uint8_t *len)
{
    uint8_t status;

    /* 确保处于接收模式 */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    config |= 0x01;  // PRIM_RX = 1（接收模式）
    SI24R1_WriteReg(SI24R1_REG_CONFIG, config);
    SI24R1_CE_HIGH();

    /* 检查是否有数据 */
    status = SI24R1_ReadStatus();
    if (!(status & 0x40)) {  // RX_DR 未置位
        return 0;  // 没有数据
    }

    /* 读取 Payload 长度 */
    *len = SI24R1_PAYLOAD_WIDTH;

    /* 读取数据 */
    SI24R1_CSN_LOW();
    SI24R1_SPI_ReadWriteByte(SI24R1_CMD_R_RX_PAYLOAD);
    for (uint8_t i = 0; i < *len; i++) {
        data[i] = SI24R1_SPI_ReadWriteByte(0xFF);
    }
    SI24R1_CSN_HIGH();

    /* 清除 RX_DR 标志 */
    SI24R1_WriteReg(SI24R1_REG_STATUS, 0x40);

    return 1;  // 收到数据
}
```

### 6.3 轮询接收（非中断方式）

```c
void SI24R1_CheckForData(void)
{
    uint8_t data[SI24R1_PAYLOAD_WIDTH];
    uint8_t len;

    if (SI24R1_ReceivePacket(data, &len)) {
        printf("RX [%d bytes]: ", len);
        for (uint8_t i = 0; i < len; i++) {
            printf("%02X ", data[i]);
        }
        printf("\r\n");
    }
}
```

### 6.4 中断接收方式

```c
/* 在 GPIO 中断回调中处理 */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == SI24R1_IRQ_PIN) {
        uint8_t data[SI24R1_PAYLOAD_WIDTH];
        uint8_t len;
        uint8_t status = SI24R1_ReadStatus();

        if (status & 0x40) {  // RX_DR
            SI24R1_ReceivePacket(data, &len);
            /* 处理接收到的数据 */
        }
        if (status & 0x20) {  // TX_DS
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x20);
        }
        if (status & 0x10) {  // MAX_RT
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x10);
            SI24R1_CSN_LOW();
            SI24R1_SPI_ReadWriteByte(SI24R1_CMD_FLUSH_TX);
            SI24R1_CSN_HIGH();
        }
    }
}
```

## 7. 完整代码示例

### 7.1 头文件 (`si24r1.h`)

```c
#ifndef __SI24R1_H__
```

### 7.2 源文件 (`si24r1.c`)

```c
#include "si24r1.h"
#include <stdio.h>

/* SPI 句柄（CubeMX 生成） */
extern SPI_HandleTypeDef hspi2;

/* ─── SPI 底层 ─── */

static uint8_t SPI_RW(uint8_t tx)
{
    uint8_t rx;
    HAL_SPI_TransmitReceive(&hspi2, &tx, &rx, 1, 10);
    return rx;
}

/* ─── 寄存器操作 ─── */

uint8_t SI24R1_ReadReg(uint8_t reg)
{
    uint8_t val;
    SI24R1_CSN_LOW();
    SPI_RW(0x00 | reg);
    val = SPI_RW(0xFF);
    SI24R1_CSN_HIGH();
    return val;
}

void SI24R1_WriteReg(uint8_t reg, uint8_t val)
{
    SI24R1_CSN_LOW();
    SPI_RW(0x20 | reg);
    SPI_RW(val);
    SI24R1_CSN_HIGH();
}

void SI24R1_ReadBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SPI_RW(0x00 | reg);
    for (uint8_t i = 0; i < len; i++) {
        buf[i] = SPI_RW(0xFF);
    }
    SI24R1_CSN_HIGH();
}

void SI24R1_WriteBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SPI_RW(0x20 | reg);
    for (uint8_t i = 0; i < len; i++) {
        SPI_RW(buf[i]);
    }
    SI24R1_CSN_HIGH();
}

uint8_t SI24R1_ReadStatus(void)
{
    uint8_t s;
    SI24R1_CSN_LOW();
    s = SPI_RW(0xFF);
    SI24R1_CSN_HIGH();
    return s;
}

/* ─── 初始化 ─── */

uint8_t SI24R1_Init(void)
{
    uint8_t addr[5] = {0x34, 0x43, 0x10, 0x10, 0x01};

    SI24R1_CE_LOW();

    SI24R1_WriteReg(0x03, 0x03);                        // SETUP_AW: 5字节地址
    SI24R1_WriteReg(0x04, (5 << 4) | 5);               // SETUP_RETR: 1000μs, 重传5次
    SI24R1_WriteReg(0x05, 40);                           // RF_CH: 2.440GHz
    SI24R1_WriteReg(0x06, (0 << 3) | (1 << 1) | 1);     // RF_SETUP: 0dBm, 2Mbps, LNA
    SI24R1_WriteBuf(0x0A, addr, 5);                     // RX_ADDR_P0
    SI24R1_WriteBuf(0x10, addr, 5);                     // TX_ADDR
    SI24R1_WriteReg(0x11, SI24R1_PAYLOAD_WIDTH);        // RX_PW_P0
    SI24R1_WriteReg(0x01, 0x01);                        // EN_AA: Pipe 0
    SI24R1_WriteReg(0x02, 0x01);                        // EN_RXADDR: Pipe 0
    SI24R1_WriteReg(0x1C, 0x01);                        // DYNPD
    SI24R1_WriteReg(0x1D, 0x04);                        // FEATURE: EN_DPL
    SI24R1_WriteReg(0x00, 0x0F);                        // CONFIG: 上电, 接收模式

    /* 清空 FIFO */
    SI24R1_CSN_LOW(); SPI_RW(0xE1); SI24R1_CSN_HIGH();
    SI24R1_CSN_LOW(); SPI_RW(0xE2); SI24R1_CSN_HIGH();

    HAL_Delay(2);
    SI24R1_CE_HIGH();

    if (SI24R1_ReadReg(0x00) != 0x0F) {
        return 0;
    }
    return 1;
}

/* ─── 发送 ─── */

uint8_t SI24R1_SendPacket(uint8_t *data, uint8_t len)
{
    if (len > SI24R1_PAYLOAD_WIDTH) len = SI24R1_PAYLOAD_WIDTH;

    SI24R1_CE_LOW();

    /* 切换发送模式 */
    SI24R1_WriteReg(0x00, SI24R1_ReadReg(0x00) & ~0x01);

    /* 清空 TX FIFO */
    SI24R1_CSN_LOW(); SPI_RW(0xE1); SI24R1_CSN_HIGH();

    /* 写入数据 */
    SI24R1_CSN_LOW();
    SPI_RW(0xA0);
    for (uint8_t i = 0; i < len; i++) SPI_RW(data[i]);
    SI24R1_CSN_HIGH();

    /* 触发发送 */
    SI24R1_CE_HIGH();
    HAL_Delay(1);
    SI24R1_CE_LOW();

    /* 等待结果 */
    for (uint32_t t = 0; t < 10000; t++) {
        uint8_t s = SI24R1_ReadStatus();
        if (s & 0x20) { SI24R1_WriteReg(0x07, 0x20); return 1; }
        if (s & 0x10) {
            SI24R1_WriteReg(0x07, 0x10);
            SI24R1_CSN_LOW(); SPI_RW(0xE1); SI24R1_CSN_HIGH();
            return 0;
        }
    }
    return 0;
}

/* ─── 接收 ─── */

uint8_t SI24R1_ReceivePacket(uint8_t *data, uint8_t *len)
{
    /* 确保接收模式 */
    SI24R1_WriteReg(0x00, SI24R1_ReadReg(0x00) | 0x01);
    SI24R1_CE_HIGH();

    if (!(SI24R1_ReadStatus() & 0x40)) return 0;

    *len = SI24R1_PAYLOAD_WIDTH;

    SI24R1_CSN_LOW();
    SPI_RW(0x61);
    for (uint8_t i = 0; i < *len; i++) data[i] = SPI_RW(0xFF);
    SI24R1_CSN_HIGH();

    SI24R1_WriteReg(0x07, 0x40);
    return 1;
}
```

## 8. 典型应用场景

### 8.1 飞控遥控器接收

飞控端作为**接收机**，遥控器端作为**发射机**。接收机持续监听数据包，收到后解析通道值控制电机。

**典型数据包格式（32 字节）：**

```
Byte 0-1:   帧头 (0xAA 0x55)
Byte 2-3:   Throttle  (油门, 1000-2000)
Byte 4-5:   Roll      (横滚, 1000-2000)
Byte 6-7:   Pitch     (俯仰, 1000-2000)
Byte 8-9:   Yaw       (偏航, 1000-2000)
Byte 10-13: AUX1-AUX4 (辅助通道)
Byte 14-29: 保留
Byte 30-31: CRC16 校验
```

### 8.2 双工通信

SI24R1 支持 Enhanced ShockBurst 协议，可以实现**带确认的可靠通信**：

```
发射端                              接收端
  │                                   │
  ├── 发送数据包 ─────────────────→  │
  │                                   ├── 收到数据，硬件自动回 ACK
  │  ←─────────── ACK ───────────── │
  │                                   │
  ├── 未收到 ACK，自动重传 ─────────→ │
  │                                   ├── 收到，回 ACK
  │  ←─────────── ACK ───────────── │
  │                                   │
  └── 收到 ACK，TX_DS 置位            └── RX_DR 置位
```

### 8.3 多机通信

利用 6 个 Pipe 可以实现一主多从通信：

| Pipe | 地址 | 用途 |
|------|------|------|
| Pipe 0 | 0x34101001 | 接收遥控器数据（或发送时使用） |
| Pipe 1 | 0x34101002 | 接收传感器数据 |
| Pipe 2-5 | 0x03, 0x04, ... | 低字节可变，高字节共享 Pipe 1 |

## 9. 常见问题

### 9.1 通信不上

**排查步骤：**

1. **检查 SPI 通信**：读取 CONFIG 寄存器（0x00），看返回值是否与写入一致
2. **检查地址一致**：发射端 TX_ADDR 必须等于接收端 RX_ADDR_P0
3. **检查频道一致**：两端 RF_CH 必须相同
4. **检查通信模式**：一端发送，另一端必须接收
5. **检查 CRC**：两端 CRC 设置必须一致（1 字节 / 2 字节）
6. **检查数据速率**：两端 RF_SETUP 速率设置必须一致

### 9.2 读到的寄存器值不对

- 确保 CSN 拉低到 SPI 通信之间至少有 **1μs** 延时
- 确保 SPI 时钟不超过 10MHz
- 检查 SPI 的 CPOL/CPHA 设置（CPOL=0, CPHA=0）

### 9.3 总是 MAX_RT（重传超限）

- 接收端是否在接收模式且 CE 为高
- 地址是否匹配
- 频道是否匹配
- 距离是否超出范围
- 电源是否稳定（3.3V 纹波 < 50mV）

### 9.4 收不到数据

- 检查 PRIM_RX 位是否为 1
- 检查 CE 是否为高电平
- 检查 EN_RXADDR 是否使能了对应 Pipe
- 检查 RX_PW_Px 是否设置了正确的载荷宽度

### 9.5 与 nRF24L01+ 通信

SI24R1 完全兼容 nRF24L01+ 协议，但需要注意：

- SI24R1 最大发射功率为 +7dBm，需在 RF_SETUP 中正确设置
- 如果 nRF24L01+ 是标准版（0dBm），SI24R1 可以收到但 nRF24L01+ 可能收不到远距离的 SI24R1 信号
- 建议两端都使用相同的功率设置
