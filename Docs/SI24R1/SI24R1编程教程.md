## 1. SI24R1 简介

SI24R1 是南京中科微电子推出的 **2.4GHz 无线收发芯片**，完全兼容 nRF24L01+ 协议，是飞控遥控器通信的理想选择。

**核心特性：**

| 特性 | 参数 |
|------|------|
| 工作频段 | 2.400 - 2.525 GHz，126 个频道 |
| 通信接口 | 4 线 SPI（最高 10MHz） |
| 数据速率 | 250kbps / 1Mbps / 2Mbps |
| 发射功率 | -12dBm ~ +7dBm（8 档可调） |
| 最大功率 | **+7dBm**（比 nRF24L01+ 高） |
| 接收灵敏度 | -83dBm @ 2Mbps |
| 工作电压 | 1.9 - 3.6V |
| 发射电流 | ~25mA @ +7dBm / ~12mA @ 0dBm |
| 接收电流 | ~14mA |
| 待机电流 | ~15μA |
| 掉电电流 | ~0.7μA |
| 数据包 | 1-32 字节，支持 Enhanced ShockBurst |
| 多通道 | 6 个接收通道（Pipe 0-5） |
| 自动应答 | 硬件自动 ACK |
| 自动重传 | 可配置次数和间隔 |

**与 nRF24L01+ 的关键差异：**

| 特性 | SI24R1 | nRF24L01+ |
|------|--------|-----------|
| 最大发射功率 | **+7dBm** | 0dBm |
| 功率档位 | 8 档（3 bit） | 4 档（2 bit） |
| RF_SETUP 功率位 | bit[4:2] | bit[4:3] |
| 通信距离 | 更远 | 标准 |
| 寄存器兼容 | 基本兼容（功率位不同） | — |

> **重要警告：** SI24R1 的 RF_SETUP 寄存器中功率位域与 nRF24L01+ **不同**！SI24R1 使用 bit[4:2]（3 bit），而 nRF24L01+ 使用 bit[4:3]（2 bit）。如果直接照搬 nRF24L01+ 的配置代码，会导致功率和数据速率设置错误。

## 2. 硬件连接（基于 DragonFly V2 原理图）

### 2.1 引脚连接

DragonFly V2 使用 **SPI2** 与 SI24R1 通信，共 6 个引脚：

```
STM32F411CEU6              SI24R1 (QFN20)
─────────────────────────────────────────────────
PB13 (SPI2_SCK)  ──────── Pin 13 (SCK)
PB14 (SPI2_MISO) ──────── Pin 11 (MISO)
PB15 (SPI2_MOSI) ──────── Pin 12 (MOSI)
PB12 (GPIO)      ──────── Pin 14 (CSN)    ← 片选，软件控制
PA4  (GPIO)      ──────── Pin 15 (CE)     ← 芯片使能，控制收发模式
PA3  (GPIO)      ──────── Pin 6  (IRQ)    ← 中断输出（低有效）
```

### 2.2 SI24R1 完整引脚定义

| 引脚 | 名称 | 功能 | DragonFly V2 连接 |
|------|------|------|-------------------|
| 1 | VDD | 电源 | 3V3（经 FB1 0R 磁珠） |
| 2 | VSS | 地 | GND |
| 3 | ANT2 | 天线端口 2 | 天线匹配网络 → 陶瓷天线 2450AT18A100E |
| 4 | ANT1 | 天线端口 1 | 同上 |
| 5 | VDD_PA | 功放电源 | 3V3（经 FB2 0R 磁珠，C3=1nF, C4=33nF 滤波） |
| 6 | **IRQ** | 中断输出（低有效） | PA3 |
| 7 | VDD | 电源 | 3V3 |
| 8 | VSS | 地 | GND |
| 9 | XC2 | 晶振输出 | 16MHz 晶振，C10=15pF |
| 10 | XC1 | 晶振输入 | 16MHz 晶振，C9=15pF |
| 11 | **MISO** | SPI 数据输出 | PB14 |
| 12 | **MOSI** | SPI 数据输入 | PB15 |
| 13 | **SCK** | SPI 时钟 | PB13 |
| 14 | **CSN** | SPI 片选（低有效） | PB12 |
| 15 | **CE** | 芯片使能 | PA4 |
| 16 | IREF | 参考电流 | 22KΩ（R1）到 GND |
| 17 | VSS | 地 | GND |
| 18 | DVDD | 数字电源 | 3V3（C2=100nF 去耦） |
| 19 | VDD | 电源 | 3V3（C1=22μF 大电容） |
| 20 | VSS | 地 | GND |
| 21 | EXPAD | 底部散热焊盘 | GND（必须大面积接地） |

### 2.3 天线匹配网络

DragonFly V2 使用陶瓷天线 **2450AT18A100E**，通过 LC 匹配网络连接：

```
L1=3.9nH, L2=8.2nH, L3=2.7nH
C5=1.5pF, C6=1pF, C7=2.2nF, C8=4.7pF
```

> 天线匹配网络值和 PCB 布局对通信距离有显著影响，不要随意修改元件值。

### 2.4 SPI 时序要求

| 参数 | 要求 |
|------|------|
| **CPOL** | 0（SCK 空闲时为低电平） |
| **CPHA** | 0（第一个时钟沿采样数据） |
| **最大时钟** | 10 MHz |
| **数据位宽** | 8 bit |
| **数据方向** | MSB First |
| **CSN 到 SCK 建立时间** | >= 2 ns |
| **CSN 无效时间** | >= 50 ns |

### 2.5 CSN 和 CE 的控制逻辑

| CSN | CE | 芯片状态 |
|-----|-----|---------|
| 0 | x | SPI 通信使能（可读写寄存器/FIFO） |
| 1 | 0 | Standby-I（待机模式） |
| 1 | 1 | 收发模式（TX 或 RX，取决于 PRIM_RX 位） |

- CE 上升沿触发发送（TX 模式）或启动接收（RX 模式）
- CE 高电平至少保持 **10μs**
- 寄存器只能在 Shutdown、Standby 和 Idle-TX 模式下配置（即 CE=0 时）

## 3. SPI 通信基础

### 3.1 SPI 命令格式

所有 SPI 通信都遵循以下格式：

```
第 1 字节：命令字（含 R/W 位 + 寄存器地址）
第 2+ 字节：数据
```

**命令字格式：**

```
Bit 7    Bit 6-0
  │        │
  │        └── 寄存器地址（5 bit，0x00 - 0x1F）
  └── R/W: 0 = 读寄存器, 1 = 写寄存器
```

### 3.2 常用命令

| 命令名 | 命令字 | 功能 |
|--------|--------|------|
| R_REGISTER | 0x00 + 地址 | 读寄存器 |
| W_REGISTER | 0x20 + 地址 | 写寄存器 |
| R_RX_PAYLOAD | 0x61 | 读取接收 FIFO |
| W_TX_PAYLOAD | 0xA0 | 写入发送 FIFO |
| FLUSH_TX | 0xE1 | 清空发送 FIFO |
| FLUSH_RX | 0xE2 | 清空接收 FIFO |
| NOP | 0xFF | 空操作（常用于读状态寄存器） |

### 3.3 读写时序

**写寄存器（W_REGISTER + 地址 + 数据）：**

```c
CSN = 0;                          // 选中器件
SPI_RW(0x20 | reg_addr);          // 命令字：写寄存器
SPI_RW(data);                     // 写入数据
CSN = 1;                          // 释放器件
```

**读寄存器（R_REGISTER + 地址 → 读回数据）：**

```c
CSN = 0;                          // 选中器件
SPI_RW(0x00 | reg_addr);          // 命令字：读寄存器
data = SPI_RW(0xFF);              // 读取数据（发送 dummy 字节）
CSN = 1;                          // 释放器件
```

## 4. 寄存器速查表

### 4.1 核心寄存器

| 地址 | 名称 | 复位值 | 功能 | 关键位 |
|------|------|--------|------|--------|
| **0x00** | CONFIG | 0x08 | 配置寄存器 | [7]保留, [6]MASK_RX_DR, [5]MASK_TX_DS, [4]MASK_MAX_RT, [3]EN_CRC, [2]CRCO, [1]PWR_UP, [0]PRIM_RX |
| **0x01** | EN_AA | 0x3F | 自动应答使能 | 每 bit 对应一个 Pipe（bit0=Pipe0, ..., bit5=Pipe5） |
| **0x02** | EN_RXADDR | 0x03 | 接收通道使能 | 每 bit 对应一个 Pipe |
| **0x03** | SETUP_AW | 0x03 | 地址宽度 | [1:0] = 01(3字节)/10(4字节)/11(5字节) |
| **0x04** | SETUP_RETR | 0x03 | 自动重传 | [7:4]ARD=重传间隔, [3:0]ARC=重传次数 |
| **0x05** | RF_CH | 0x02 | 频道选择 | [6:0] = 0-125（2400MHz + 频道号） |
| **0x06** | RF_SETUP | 0x0E | 射频设置 | [7:5]保留, **[4:2]RF_PWR(3bit, SI24R1特有)**, [1]RF_DR_LOW, [0]LNA_HCURR |
| **0x07** | STATUS | 0x0E | 状态寄存器 | [7]保留, [6]RX_DR, [5]TX_DS, [4]MAX_RT, [3:1]RX_P_NO, [0]TX_FULL |
| **0x08** | OBSERVE_TX | 0x00 | 发送观察 | [7:4]PLOS_CNT=丢包计数, [3:0]ARC_CNT=重传计数 |
| **0x09** | RPD | 0x00 | 载波检测 | [0]RPD=1 表示检测到信号（> -64dBm） |
| **0x0A-0x0F** | RX_ADDR_P0-P5 | — | 接收通道地址 | P0/P1 可设全 5 字节，P2-P5 只能设最低字节 |
| **0x10** | TX_ADDR | — | 发送地址 | 5 字节，使用自动 ACK 时须等于 RX_ADDR_P0 |
| **0x11-0x16** | RX_PW_P0-P5 | 0x00 | 各通道载荷宽度 | 1-32 字节 |
| **0x17** | FIFO_STATUS | 0x11 | FIFO 状态 | [7]保留, [6]TX_REUSE, [5]TX_FULL, [4]TX_EMPTY, [1]RX_FULL, [0]RX_EMPTY |
| **0x1C** | DYNPD | 0x00 | 动态负载使能 | 每 bit 对应一个 Pipe |
| **0x1D** | FEATURE | 0x00 | 特性使能 | [2]EN_DPL, [1]EN_ACK_PAY, [0]EN_DYN_ACK |

### 4.2 RF_SETUP 寄存器详解（SI24R1 特有）

> **这是 SI24R1 与 nRF24L01+ 差异最大的寄存器，必须注意！**

| 位 | 名称 | 含义 |
|----|------|------|
| 7:5 | — | 保留，写 0 |
| **4:2** | **RF_PWR** | **发射功率（3 bit）：** 000=-12dBm, 001=-6dBm, 010=-4dBm, 011=0dBm, 100=+1dBm, 101=+3dBm, 110=+4dBm, 111=+7dBm |
| 1 | RF_DR_LOW | 数据速率：0=2Mbps(bit1=0时), 1=250kbps |
| 0 | LNA_HCURR | LNA 增益：0=低增益, 1=高增益 |

**数据速率配置：**

| RF_DR_LOW | 速率 | 灵敏度 | 适用场景 |
|-----------|------|--------|----------|
| 0 | 2 Mbps | -83 dBm | 低延迟（推荐飞控使用） |
| 0* | 1 Mbps | -85 dBm | 兼顾速率和距离 |
| 1 | 250 kbps | -94 dBm | 远距离通信 |

> *注：SI24R1 没有 RF_DR_HIGH 位（该位被用作功率位），因此 1Mbps 和 2Mbps 通过 RF_DR_LOW=0 设置，实际速率由固件自动协商。在大多数情况下，设置 RF_DR_LOW=0 即可获得 2Mbps。

### 4.3 STATUS 寄存器详解

| 位 | 名称 | 含义 |
|----|------|------|
| 7 | — | 保留 |
| 6 | RX_DR | 收到数据（写 1 清除） |
| 5 | TX_DS | 发送成功（写 1 清除） |
| 4 | MAX_RT | 达到最大重传次数（写 1 清除） |
| 3:1 | RX_P_NO | 收到数据来自哪个 Pipe（000-101 = Pipe 0-5，110-111 = 空） |
| 0 | TX_FULL | 发送 FIFO 已满 |

### 4.4 地址配置规则

- **RX_ADDR_P0**（0x0A）和 **RX_ADDR_P1**（0x0B）：可设置完整 5 字节地址
- **RX_ADDR_P2~P5**（0x0C~0x0F）：只能设置最低字节（LSB），高 4 字节自动与 RX_ADDR_P1[39:8] 共享
- **TX_ADDR**（0x10）：发射地址，5 字节
- 使用自动 ACK 时，**TX_ADDR 必须等于 RX_ADDR_P0**
- 地址写入顺序：**LSByte 优先**（最低字节先写入）

## 5. 初始化流程

### 5.1 CubeMX 配置 SPI2

在 CubeMX 中配置 SPI2：

| 参数 | 设置值 | 说明 |
|------|--------|------|
| **Mode** | Full-Duplex Master | 全双工主模式 |
| **NSS** | Software | CSN 用 GPIO 软件控制 |
| **Data Size** | 8 bit | — |
| **CPOL** | Low | SCK 空闲低电平 |
| **CPHA** | 1 Edge | 第一个时钟沿采样 |
| **Prescaler** | 8 | 42MHz / 8 = **5.25MHz**（安全，低于 10MHz 上限） |
| **Baud Rate** | 5.25 MBits/s | — |

> **时钟计算：** STM32F411 的 SPI2 挂载在 **APB1** 总线上，APB1 外设时钟为 **42MHz**（HCLK=84MHz，APB1 预分频器=2）。不是 84MHz！  
> - Prescaler=4：42/4=10.5MHz → **超过** 10MHz 上限，不推荐  
> - Prescaler=8：42/8=5.25MHz → 安全，推荐  
> - Prescaler=16：42/16=2.625MHz → 保守，调试时可用

PB12（CSN）和 PA4（CE）设为 GPIO_Output（推挽输出，无上拉，高速）。  
PA3（IRQ）设为 GPIO_Input（上拉，因为 IRQ 是低有效）。

### 5.2 上电初始化流程

```
1. CE = 0（进入待机模式，允许配置寄存器）
2. 配置所有寄存器（地址、频道、功率、速率等）
3. 设置 CONFIG.PWR_UP = 1（上电）
4. 等待 >= 1.5ms（晶振起振稳定）
5. 清空 FIFO（FLUSH_TX + FLUSH_RX）
6. CE = 1（激活收发模式）
```

### 5.3 初始化代码

```c
/* ──────────── 引脚定义（DragonFly V2 原理图） ──────────── */
#define SI24R1_CSN_PORT     GPIOB
#define SI24R1_CSN_PIN      GPIO_PIN_12
#define SI24R1_CE_PORT      GPIOA
#define SI24R1_CE_PIN       GPIO_PIN_4
#define SI24R1_IRQ_PORT     GPIOA
#define SI24R1_IRQ_PIN      GPIO_PIN_3

/* 引脚控制宏 */
#define SI24R1_CSN_LOW()    HAL_GPIO_WritePin(SI24R1_CSN_PORT, SI24R1_CSN_PIN, GPIO_PIN_RESET)
#define SI24R1_CSN_HIGH()   HAL_GPIO_WritePin(SI24R1_CSN_PORT, SI24R1_CSN_PIN, GPIO_PIN_SET)
#define SI24R1_CE_LOW()     HAL_GPIO_WritePin(SI24R1_CE_PORT, SI24R1_CE_PIN, GPIO_PIN_RESET)
#define SI24R1_CE_HIGH()    HAL_GPIO_WritePin(SI24R1_CE_PORT, SI24R1_CE_PIN, GPIO_PIN_SET)
#define SI24R1_IRQ_READ()   HAL_GPIO_ReadPin(SI24R1_IRQ_PORT, SI24R1_IRQ_PIN)

/* 寄存器命令 */
#define SI24R1_CMD_R_REGISTER        0x00
#define SI24R1_CMD_W_REGISTER        0x20
#define SI24R1_CMD_R_RX_PAYLOAD      0x61
#define SI24R1_CMD_W_TX_PAYLOAD      0xA0
#define SI24R1_CMD_FLUSH_TX          0xE1
#define SI24R1_CMD_FLUSH_RX          0xE2
#define SI24R1_CMD_NOP               0xFF

/* 寄存器地址 */
#define SI24R1_REG_CONFIG            0x00
#define SI24R1_REG_EN_AA             0x01
#define SI24R1_REG_EN_RXADDR         0x02
#define SI24R1_REG_SETUP_AW          0x03
#define SI24R1_REG_SETUP_RETR        0x04
#define SI24R1_REG_RF_CH             0x05
#define SI24R1_REG_RF_SETUP          0x06
#define SI24R1_REG_STATUS            0x07
#define SI24R1_REG_RX_ADDR_P0        0x0A
#define SI24R1_REG_TX_ADDR           0x10
#define SI24R1_REG_RX_PW_P0          0x11
#define SI24R1_REG_FIFO_STATUS       0x17
#define SI24R1_REG_DYNPD             0x1C
#define SI24R1_REG_FEATURE           0x1D

/* 参数 */
#define SI24R1_PAYLOAD_WIDTH         32
#define SI24R1_ADDR_WIDTH            5
#define SI24R1_RF_CHANNEL            40      /* 2.440GHz */

/* SI24R1 RF_SETUP 功率选项（3 bit，SI24R1 特有） */
#define SI24R1_PWR_N12dBm           0x00    /* -12dBm */
#define SI24R1_PWR_N6dBm            0x04    /* -6dBm  */
#define SI24R1_PWR_N4dBm            0x08    /* -4dBm  */
#define SI24R1_PWR_0dBm             0x0C    /*  0dBm  */
#define SI24R1_PWR_P1dBm            0x10    /* +1dBm  */
#define SI24R1_PWR_P3dBm            0x14    /* +3dBm  */
#define SI24R1_PWR_P4dBm            0x18    /* +4dBm  */
#define SI24R1_PWR_P7dBm            0x1C    /* +7dBm  */

/* ───────────────── SPI 底层函数 ───────────────── */

extern SPI_HandleTypeDef hspi2;

static uint8_t SI24R1_SPI_RW(uint8_t tx_data)
{
    uint8_t rx_data;
    HAL_SPI_TransmitReceive(&hspi2, &tx_data, &rx_data, 1, 10);
    return rx_data;
}

/* ───────────────── 寄存器读写 ───────────────── */

uint8_t SI24R1_ReadReg(uint8_t reg)
{
    uint8_t value;
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_R_REGISTER | reg);
    value = SI24R1_SPI_RW(0xFF);
    SI24R1_CSN_HIGH();
    return value;
}

void SI24R1_WriteReg(uint8_t reg, uint8_t value)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_W_REGISTER | reg);
    SI24R1_SPI_RW(value);
    SI24R1_CSN_HIGH();
}

void SI24R1_ReadBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_R_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        buf[i] = SI24R1_SPI_RW(0xFF);
    }
    SI24R1_CSN_HIGH();
}

void SI24R1_WriteBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_W_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        SI24R1_SPI_RW(buf[i]);
    }
    SI24R1_CSN_HIGH();
}

uint8_t SI24R1_ReadStatus(void)
{
    uint8_t status;
    SI24R1_CSN_LOW();
    status = SI24R1_SPI_RW(SI24R1_CMD_NOP);
    SI24R1_CSN_HIGH();
    return status;
}

/* ───────────────── 初始化 ───────────────── */

uint8_t SI24R1_Init(void)
{
    uint8_t addr[SI24R1_ADDR_WIDTH] = {0x34, 0x43, 0x10, 0x10, 0x01};

    /* 1. 进入待机模式（允许配置寄存器） */
    SI24R1_CE_LOW();

    /* 2. 设置地址宽度：5 字节 */
    SI24R1_WriteReg(SI24R1_REG_SETUP_AW, 0x03);

    /* 3. 设置自动重传：间隔 1000μs，最多重传 5 次 */
    /*    ARD = 0101 (1000μs), ARC = 0101 (5 次) */
    SI24R1_WriteReg(SI24R1_REG_SETUP_RETR, (5 << 4) | 5);

    /* 4. 设置频道：2.440GHz */
    SI24R1_WriteReg(SI24R1_REG_RF_CH, SI24R1_RF_CHANNEL);

    /* 5. 设置射频参数：0dBm, 2Mbps, LNA 高增益 */
    /*    SI24R1 RF_SETUP: bit[4:2]=RF_PWR(011=0dBm), bit[1]=RF_DR_LOW(0=2Mbps), bit[0]=LNA(1) */
    SI24R1_WriteReg(SI24R1_REG_RF_SETUP, SI24R1_PWR_0dBm | (0 << 1) | (1 << 0));

    /* 6. 设置接收地址（Pipe 0） */
    SI24R1_WriteBuf(SI24R1_REG_RX_ADDR_P0, addr, SI24R1_ADDR_WIDTH);

    /* 7. 设置发送地址（必须与 RX_ADDR_P0 相同，启用自动 ACK 时） */
    SI24R1_WriteBuf(SI24R1_REG_TX_ADDR, addr, SI24R1_ADDR_WIDTH);

    /* 8. 设置 Payload 宽度 */
    SI24R1_WriteReg(SI24R1_REG_RX_PW_P0, SI24R1_PAYLOAD_WIDTH);

    /* 9. 使能 Pipe 0 自动应答 */
    SI24R1_WriteReg(SI24R1_REG_EN_AA, 0x01);

    /* 10. 使能接收通道 0 */
    SI24R1_WriteReg(SI24R1_REG_EN_RXADDR, 0x01);

    /* 11. 使能动态 Payload 长度 */
    SI24R1_WriteReg(SI24R1_REG_DYNPD, 0x01);
    SI24R1_WriteReg(SI24R1_REG_FEATURE, 0x04);  /* EN_DPL=1 */

    /* 12. 上电，设为接收模式 */
    /*     CONFIG: MASK=0(不屏蔽中断), CRC=2字节, PWR_UP=1, PRIM_RX=1 */
    SI24R1_WriteReg(SI24R1_REG_CONFIG, 0x0F);

    /* 13. 等待晶振稳定（>= 1.5ms） */
    HAL_Delay(2);

    /* 14. 清空 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_FLUSH_TX);
    SI24R1_CSN_HIGH();
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_FLUSH_RX);
    SI24R1_CSN_HIGH();

    /* 15. 使能接收 */
    SI24R1_CE_HIGH();

    /* 验证：回读 CONFIG 寄存器 */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    if (config != 0x0F) {
        printf("SI24R1 init failed! CONFIG=0x%02X\r\n", config);
        return 0;
    }

    printf("SI24R1 init OK\r\n");
    return 1;
}
```

### 5.4 发射功率与速率选择指南

**发射功率（RF_SETUP[4:2]）：**

| RF_PWR[2:0] | 功率 | 电流 | 适用场景 |
|-------------|------|------|----------|
| 000 | -12 dBm | ~7mA | 近距离测试 |
| 001 | -6 dBm | ~7.5mA | 室内短距离 |
| 010 | -4 dBm | ~8mA | — |
| 011 | 0 dBm | ~12mA | 一般室外 |
| 100 | +1 dBm | ~15mA | — |
| 101 | +3 dBm | ~18mA | — |
| 110 | +4 dBm | ~20mA | — |
| **111** | **+7 dBm** | **~25mA** | **远距离（推荐）** |

> 飞控遥控器推荐使用 **+7dBm** 以获得最大通信距离，对应的宏为 `SI24R1_PWR_P7dBm`。

**数据速率：**

| RF_DR_LOW | 速率 | 灵敏度 | 适合场景 |
|-----------|------|--------|----------|
| 0 | 2 Mbps | -83 dBm | 低延迟，飞控推荐 |
| 1 | 250 kbps | -94 dBm | 远距离，抗干扰强 |

## 6. 数据收发

### 6.1 发送数据

```c
uint8_t SI24R1_SendPacket(uint8_t *data, uint8_t len)
{
    uint8_t status;

    /* 限制长度 */
    if (len > SI24R1_PAYLOAD_WIDTH) {
        len = SI24R1_PAYLOAD_WIDTH;
    }

    /* 1. 切换到待机模式 */
    SI24R1_CE_LOW();

    /* 2. 切换到发送模式（PRIM_RX = 0） */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    config &= ~0x01;
    SI24R1_WriteReg(SI24R1_REG_CONFIG, config);

    /* 3. 清空发送 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_FLUSH_TX);
    SI24R1_CSN_HIGH();

    /* 4. 写入数据到发送 FIFO */
    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_W_TX_PAYLOAD);
    for (uint8_t i = 0; i < len; i++) {
        SI24R1_SPI_RW(data[i]);
    }
    SI24R1_CSN_HIGH();

    /* 5. CE 脉冲触发发送（>= 10μs） */
    SI24R1_CE_HIGH();
    HAL_Delay(1);  /* 1ms，远大于 10μs 要求 */
    SI24R1_CE_LOW();

    /* 6. 等待发送完成 */
    uint32_t timeout = 10000;
    while (timeout--) {
        status = SI24R1_ReadStatus();
        if (status & 0x20) {  /* TX_DS：发送成功 */
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x20);  /* 清除标志 */
            return 1;
        }
        if (status & 0x10) {  /* MAX_RT：达到最大重传次数 */
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x10);  /* 清除标志 */
            /* 清空发送 FIFO，丢弃失败的数据 */
            SI24R1_CSN_LOW();
            SI24R1_SPI_RW(SI24R1_CMD_FLUSH_TX);
            SI24R1_CSN_HIGH();
            return 0;
        }
    }

    return 0;  /* 超时 */
}
```

### 6.2 接收数据

```c
uint8_t SI24R1_ReceivePacket(uint8_t *data, uint8_t *len)
{
    uint8_t status;

    /* 确保处于接收模式 */
    uint8_t config = SI24R1_ReadReg(SI24R1_REG_CONFIG);
    if (!(config & 0x01)) {  /* PRIM_RX != 1 */
        config |= 0x01;
        SI24R1_WriteReg(SI24R1_REG_CONFIG, config);
    }
    SI24R1_CE_HIGH();

    /* 检查是否有数据 */
    status = SI24R1_ReadStatus();
    if (!(status & 0x40)) {  /* RX_DR 未置位 */
        return 0;
    }

    /* 读取 Payload */
    *len = SI24R1_PAYLOAD_WIDTH;

    SI24R1_CSN_LOW();
    SI24R1_SPI_RW(SI24R1_CMD_R_RX_PAYLOAD);
    for (uint8_t i = 0; i < *len; i++) {
        data[i] = SI24R1_SPI_RW(0xFF);
    }
    SI24R1_CSN_HIGH();

    /* 清除 RX_DR 标志 */
    SI24R1_WriteReg(SI24R1_REG_STATUS, 0x40);

    return 1;
}
```

### 6.3 中断接收方式

IRQ 引脚在以下情况会拉低（任一事件触发）：

| 事件 | 清除方法 |
|------|---------|
| 收到数据（RX_DR） | 写 1 到 STATUS[6] 或读取 RX FIFO |
| 发送成功（TX_DS） | 写 1 到 STATUS[5] |
| 达到最大重传（MAX_RT） | 写 1 到 STATUS[4] 或清空 TX FIFO |

```c
/* 在 GPIO 中断回调中处理（PA3 下降沿触发） */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == SI24R1_IRQ_PIN) {
        uint8_t data[SI24R1_PAYLOAD_WIDTH];
        uint8_t len;
        uint8_t status = SI24R1_ReadStatus();

        if (status & 0x40) {  /* RX_DR */
            SI24R1_CSN_LOW();
            SI24R1_SPI_RW(SI24R1_CMD_R_RX_PAYLOAD);
            for (uint8_t i = 0; i < SI24R1_PAYLOAD_WIDTH; i++) {
                data[i] = SI24R1_SPI_RW(0xFF);
            }
            SI24R1_CSN_HIGH();
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x40);
            /* TODO: 处理 data */
        }
        if (status & 0x20) {  /* TX_DS */
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x20);
        }
        if (status & 0x10) {  /* MAX_RT */
            SI24R1_WriteReg(SI24R1_REG_STATUS, 0x10);
            SI24R1_CSN_LOW();
            SI24R1_SPI_RW(SI24R1_CMD_FLUSH_TX);
            SI24R1_CSN_HIGH();
        }
    }
}
```

### 7.2 源文件 (`si24r1.c`)

```c
#include "si24r1.h"
#include <stdio.h>

/* SPI 句柄（CubeMX 生成） */
extern SPI_HandleTypeDef hspi2;

/* ─── 寄存器命令 ─── */
#define CMD_R_REGISTER    0x00
#define CMD_W_REGISTER    0x20
#define CMD_R_RX_PAYLOAD  0x61
#define CMD_W_TX_PAYLOAD  0xA0
#define CMD_FLUSH_TX      0xE1
#define CMD_FLUSH_RX      0xE2
#define CMD_NOP           0xFF

/* ─── 寄存器地址 ─── */
#define REG_CONFIG        0x00
#define REG_EN_AA         0x01
#define REG_EN_RXADDR     0x02
#define REG_SETUP_AW      0x03
#define REG_SETUP_RETR    0x04
#define REG_RF_CH         0x05
#define REG_RF_SETUP      0x06
#define REG_STATUS        0x07
#define REG_RX_ADDR_P0    0x0A
#define REG_TX_ADDR       0x10
#define REG_RX_PW_P0      0x11
#define REG_DYNPD         0x1C
#define REG_FEATURE       0x1D

#define ADDR_WIDTH        5
#define RF_CHANNEL        40

/* ─── SPI 底层 ─── */

static uint8_t SPI_RW(uint8_t tx)
{
    uint8_t rx;
    HAL_SPI_TransmitReceive(&hspi2, &tx, &rx, 1, 10);
    return rx;
}

/* ─── 寄存器操作 ─── */

uint8_t SI24R1_ReadReg(uint8_t reg)
{
    uint8_t val;
    SI24R1_CSN_LOW();
    SPI_RW(CMD_R_REGISTER | reg);
    val = SPI_RW(0xFF);
    SI24R1_CSN_HIGH();
    return val;
}

void SI24R1_WriteReg(uint8_t reg, uint8_t val)
{
    SI24R1_CSN_LOW();
    SPI_RW(CMD_W_REGISTER | reg);
    SPI_RW(val);
    SI24R1_CSN_HIGH();
}

static void ReadBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SPI_RW(CMD_R_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        buf[i] = SPI_RW(0xFF);
    }
    SI24R1_CSN_HIGH();
}

static void WriteBuf(uint8_t reg, uint8_t *buf, uint8_t len)
{
    SI24R1_CSN_LOW();
    SPI_RW(CMD_W_REGISTER | reg);
    for (uint8_t i = 0; i < len; i++) {
        SPI_RW(buf[i]);
    }
    SI24R1_CSN_HIGH();
}

uint8_t SI24R1_ReadStatus(void)
{
    uint8_t s;
    SI24R1_CSN_LOW();
    s = SPI_RW(CMD_NOP);
    SI24R1_CSN_HIGH();
    return s;
}

/* ─── 初始化 ─── */

uint8_t SI24R1_Init(void)
{
    uint8_t addr[ADDR_WIDTH] = {0x34, 0x43, 0x10, 0x10, 0x01};

    SI24R1_CE_LOW();

    SI24R1_WriteReg(REG_SETUP_AW, 0x03);                      /* 5 字节地址 */
    SI24R1_WriteReg(REG_SETUP_RETR, (5 << 4) | 5);            /* 1000μs, 重传 5 次 */
    SI24R1_WriteReg(REG_RF_CH, RF_CHANNEL);                    /* 2.440GHz */
    SI24R1_WriteReg(REG_RF_SETUP, SI24R1_PWR_0dBm | (0 << 1) | 1); /* 0dBm, 2Mbps */
    WriteBuf(REG_RX_ADDR_P0, addr, ADDR_WIDTH);                /* RX 地址 */
    WriteBuf(REG_TX_ADDR, addr, ADDR_WIDTH);                   /* TX 地址 */
    SI24R1_WriteReg(REG_RX_PW_P0, SI24R1_PAYLOAD_WIDTH);      /* Payload 宽度 */
    SI24R1_WriteReg(REG_EN_AA, 0x01);                          /* 使能 Pipe 0 ACK */
    SI24R1_WriteReg(REG_EN_RXADDR, 0x01);                      /* 使能 Pipe 0 */
    SI24R1_WriteReg(REG_DYNPD, 0x01);                          /* 动态长度 */
    SI24R1_WriteReg(REG_FEATURE, 0x04);                        /* EN_DPL */
    SI24R1_WriteReg(REG_CONFIG, 0x0F);                         /* 上电, 接收模式 */

    HAL_Delay(2);  /* 等待晶振稳定 */

    /* 清空 FIFO */
    SI24R1_CSN_LOW(); SPI_RW(CMD_FLUSH_TX); SI24R1_CSN_HIGH();
    SI24R1_CSN_LOW(); SPI_RW(CMD_FLUSH_RX); SI24R1_CSN_HIGH();

    SI24R1_CE_HIGH();

    if (SI24R1_ReadReg(REG_CONFIG) != 0x0F) {
        return 0;
    }
    return 1;
}

/* ─── 发送 ─── */

uint8_t SI24R1_SendPacket(uint8_t *data, uint8_t len)
{
    if (len > SI24R1_PAYLOAD_WIDTH) len = SI24R1_PAYLOAD_WIDTH;

    SI24R1_CE_LOW();

    /* 切换发送模式 */
    SI24R1_WriteReg(REG_CONFIG, SI24R1_ReadReg(REG_CONFIG) & ~0x01);

    /* 清空 TX FIFO */
    SI24R1_CSN_LOW(); SPI_RW(CMD_FLUSH_TX); SI24R1_CSN_HIGH();

    /* 写入数据 */
    SI24R1_CSN_LOW();
    SPI_RW(CMD_W_TX_PAYLOAD);
    for (uint8_t i = 0; i < len; i++) SPI_RW(data[i]);
    SI24R1_CSN_HIGH();

    /* CE 脉冲触发发送 */
    SI24R1_CE_HIGH();
    HAL_Delay(1);
    SI24R1_CE_LOW();

    /* 等待结果 */
    for (uint32_t t = 0; t < 10000; t++) {
        uint8_t s = SI24R1_ReadStatus();
        if (s & 0x20) { SI24R1_WriteReg(REG_STATUS, 0x20); return 1; }
        if (s & 0x10) {
            SI24R1_WriteReg(REG_STATUS, 0x10);
            SI24R1_CSN_LOW(); SPI_RW(CMD_FLUSH_TX); SI24R1_CSN_HIGH();
            return 0;
        }
    }
    return 0;
}

/* ─── 接收 ─── */

uint8_t SI24R1_ReceivePacket(uint8_t *data, uint8_t *len)
{
    /* 确保接收模式 */
    SI24R1_WriteReg(REG_CONFIG, SI24R1_ReadReg(REG_CONFIG) | 0x01);
    SI24R1_CE_HIGH();

    if (!(SI24R1_ReadStatus() & 0x40)) return 0;

    *len = SI24R1_PAYLOAD_WIDTH;

    SI24R1_CSN_LOW();
    SPI_RW(CMD_R_RX_PAYLOAD);
    for (uint8_t i = 0; i < *len; i++) data[i] = SPI_RW(0xFF);
    SI24R1_CSN_HIGH();

    SI24R1_WriteReg(REG_STATUS, 0x40);
    return 1;
}
```

## 8. 典型应用场景

### 8.1 飞控遥控器接收

飞控端作为**接收机**，遥控器端作为**发射机**。接收机持续监听数据包，收到后解析通道值控制电机。

**典型数据包格式（32 字节）：**

```
Byte 0-1:   帧头 (0xAA 0x55)
Byte 2-3:   Throttle  (油门, 1000-2000)
Byte 4-5:   Roll      (横滚, 1000-2000)
Byte 6-7:   Pitch     (俯仰, 1000-2000)
Byte 8-9:   Yaw       (偏航, 1000-2000)
Byte 10-13: AUX1-AUX4 (辅助通道)
Byte 14-29: 保留
Byte 30-31: CRC16 校验
```

### 8.2 Enhanced ShockBurst 自动应答流程

```
发射端                              接收端
  │                                   │
  ├── 发送数据包 ─────────────────→  │
  │                                   ├── 收到数据，硬件自动回 ACK
  │  ←─────────── ACK ───────────── │
  │                                   │
  ├── 未收到 ACK，自动重传 ─────────→ │
  │                                   ├── 收到，回 ACK
  │  ←─────────── ACK ───────────── │
  │                                   │
  └── 收到 ACK，TX_DS 置位            └── RX_DR 置位
```

### 8.3 多机通信

利用 6 个 Pipe 可以实现一主多从通信：

| Pipe | 地址 | 用途 |
|------|------|------|
| Pipe 0 | 0x34101001 | 接收遥控器数据（发送时也使用此地址） |
| Pipe 1 | 0x34101002 | 接收传感器数据 |
| Pipe 2-5 | 0x03, 0x04, ... | 低字节可变，高 4 字节共享 Pipe 1 地址 |

## 9. 常见问题

### 9.1 通信不上

**排查步骤：**

1. **检查 SPI 通信**：读取 CONFIG 寄存器（0x00），看返回值是否与写入一致
2. **检查地址一致**：发射端 TX_ADDR 必须等于接收端 RX_ADDR_P0
3. **检查频道一致**：两端 RF_CH 必须相同
4. **检查通信模式**：一端发送，另一端必须接收
5. **检查 CRC**：两端 CRC 设置必须一致（1 字节 / 2 字节）
6. **检查数据速率**：两端速率设置必须一致

### 9.2 读到的寄存器值不对

- 确保 CSN 拉低到 SPI 通信之间至少有 **2ns** 延时
- 确保 SPI 时钟不超过 10MHz（SPI2 在 APB1=42MHz 下，Prescaler=8 得 5.25MHz，安全）
- 检查 SPI 的 CPOL/CPHA 设置（CPOL=0, CPHA=0）
- 读取寄存器时，命令字节之后需要发送 dummy 字节（0xFF）来产生时钟

### 9.3 总是 MAX_RT（重传超限）

- 接收端是否在接收模式且 CE 为高
- 地址是否匹配
- 频道是否匹配
- 距离是否超出范围
- 电源是否稳定（3.3V 纹波 < 50mV）
- VDD_PA 引脚供电是否正常（经 FB2 磁珠，检查 C3/C4 滤波电容）

### 9.4 收不到数据

- 检查 PRIM_RX 位是否为 1
- 检查 CE 是否为高电平
- 检查 EN_RXADDR 是否使能了对应 Pipe
- 检查 RX_PW_Px 是否设置了正确的载荷宽度
- 检查 IRQ 引脚状态（低电平表示有中断事件）

### 9.5 SI24R1 与 nRF24L01+ 代码兼容注意事项

SI24R1 与 nRF24L01+ 有一个关键寄存器差异：

| 寄存器 | nRF24L01+ | SI24R1 |
|--------|-----------|--------|
| RF_SETUP[4:3] | RF_PWR（2 bit） | RF_PWR[4:2]（3 bit），bit[2] 是额外功率位 |
| RF_SETUP[2] | RF_DR_HIGH（数据速率高位） | **RF_PWR[0]**（功率最低位） |

**如果直接使用 nRF24L01+ 的代码：**
- `(0 << 3) | (1 << 1) | 1` = 0x03 → SI24R1 解读为 -12dBm + 250kbps（错误！）
- 正确写法：`SI24R1_PWR_0dBm | (0 << 1) | 1` = 0x0D → 0dBm + 2Mbps

**建议：** 使用教程中提供的 `SI24R1_PWR_xxx` 宏来设置功率，避免直接使用魔数移位。

### 9.6 初始化后无法通信

上电初始化顺序很重要：

1. CE 必须先拉低再配置寄存器
2. PWR_UP 置 1 后必须等待 ≥ 1.5ms（晶振稳定时间）
3. 所有寄存器配置完成后才能拉高 CE
4. 发送和接收模式切换时，先拉低 CE，修改 PRIM_RX 位，再拉高 CE
