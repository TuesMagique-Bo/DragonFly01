## 1. MPU9250 简介

MPU-9250 是 InvenSense 的 **9 轴 MotionTracking 器件**（QFN 3×3×1 mm）：一颗芯片里是 3 轴陀螺 + 3 轴加速度计，另一颗是 **AK8963 磁力计**。飞控用它测角速度、线加速度，再解算出 roll / pitch / yaw，交给 PID。

**核心特性（规格书 PS-MPU-9250A-01）：**

| 特性 | 参数 |
|------|------|
| 陀螺量程 | ±250 / ±500 / ±1000 / ±2000 °/s，16-bit ADC |
| 加计测量程 | ±2 / ±4 / ±8 / ±16 g，16-bit ADC |
| 磁力计量程 | ±4800 µT，默认 14-bit（0.6 µT/LSB） |
| 主接口 | I2C 最高 **400 kHz**，或 SPI |
| 辅助 I2C | 可直连外部传感器；旁路后主机可访问 AK8963 |
| 工作电压 | VDD 2.4–3.6 V；VDDIO 1.71 V–VDD |
| FIFO | 512 字节 |
| 封装 | QFN24 |

**飞控中的作用：**

- **角速度**：陀螺测机体旋转，PID 阻尼振荡
- **加速度**：静止时估计重力方向 → roll / pitch
- **磁力计**（可选）：提供航向，抑制 yaw 漂移
- 本工程 `Control_Update()` 已通过 `IMU_GetAttitude()` 取姿态，传感器驱动应填进 `Modules/IMU`

**WHO_AM_I：** 寄存器 `0x75` 复位值为 **0x71**。读到 `0x73` 多为 MPU9255，`0xEA` 多为 ICM-20948（本板 BOM 可选，见原理图注释）。

## 2. 硬件连接（基于 DragonFly V2 原理图）

原理图第 4 页为 IMU / 气压计；第 3 页为 MCU。板子标注：

```
MPU9250: R34 ON, FB3 ON, C62 NC, C63 NC, U20 NC
ICM20948: R34 NC, FB3 NC, C62 ON, C63 ON, U20 ON
```

本教程按 **已贴 MPU9250（U19）** 编写。

### 2.1 与 MCU 的连接

DragonFly V2 用 **I2C1** 访问 MPU9250，CubeMX 已配好：

```
STM32F411CEU6                 MPU9250 U19 (QFN24)
────────────────────────────────────────────────
PB6  (I2C1_SCL) ──────────── Pin 23  SCL/SCLK
PB7  (I2C1_SDA) ──────────── Pin 24  SDA/SDI
IMU_INT 网络     ──────────── Pin 1   INT
3V3               ──────────── Pin 13  VDD、Pin 8 VDDIO（经 FB3）
GND               ──────────── Pin 18  GND、底部焊盘
```

| MPU9250 引脚 | 名称 | 本板用途 |
|--------------|------|----------|
| 1 | INT | 数据就绪中断（网络 `IMU_INT`，接到 MCU 页） |
| 7 / 21 | AUX_CL / AUX_DA | 内部连 AK8963；旁路后主机可访问磁力计 |
| 8 | VDDIO | 数字 IO 电源 |
| 9 | SDO/AD0 | I2C 地址 LSB |
| 13 | VDD | 模拟电源 |
| 22 | nCS | I2C 模式必须保持高电平 |
| 23 / 24 | SCL / SDA | I2C1 |

当前 CubeMX **尚未把 `IMU_INT` 配成 EXTI**。学习阶段用 1 ms 轮询即可（`StartDefaultTask` 里已有 `IMU_Update()`）。要用中断时，在原理图 MCU 页核对 `IMU_INT` 实际接到哪根 GPIO，再在 CubeMX 里配置。

### 2.2 I2C 地址（AD0）

规格书：7 位地址为 `110100X`，**X = AD0 引脚电平**。

| AD0 | 7 位地址 | HAL 参数（左移 1 位） |
|-----|----------|------------------------|
| 0 | **0x68** | `0xD0` |
| 1 | **0x69** | `0xD2` |

本工程 `IMU_Init()` 已按 **0x69** 探测 WHO_AM_I，与 AD0 接高一致。若读失败，改扫 `0x68`。

### 2.3 同总线设备

原理图第 4 页 SPL06 有两个封装位：

| 器件 | 7 位地址 | 说明 |
|------|----------|------|
| MPU9250 | 0x68 或 **0x69** | 9 轴 IMU |
| SPL06 U10 | **0x76** | 默认贴装位 |
| SPL06 U8（NC） | 0x77 | 未贴时不要访问 |
| AK8963 | **0x0C** | 打开 MPU 旁路后才出现在总线上 |

> 三个地址不冲突，可共享 I2C1。不要在未开旁路时去读 `0x0C`。

### 2.4 CubeMX 中的 I2C1（已配置）

| 参数 | 本工程实际值 |
|------|----------------|
| 引脚 | PB6=SCL，PB7=SDA，开漏 |
| 速率 | **400 kHz**（Fast Mode，手册上限） |
| 寻址 | 7-bit |

## 3. I2C 通信基础

MPU9250 在主 I2C 上始终是 **从机**。本工程用 HAL：

```c
HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR << 1, reg, I2C_MEMADD_SIZE_8BIT, buf, len, 100);
HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, reg, I2C_MEMADD_SIZE_8BIT, &val, 1, 100);
```

**注意：**

- `DevAddress` 必须是 **7 位地址左移 1 位**
- 加计 / 陀螺 / 温度是大端 16 位，从 `ACCEL_XOUT_H (0x3B)` 起可一次读 14 字节
- 写完 `PWR_MGMT_1` 的复位位后，要等 **100 ms** 再访问
- I2C1 与 SPL06 共用，操作应串行；FreeRTOS 里建议加互斥锁

## 4. 寄存器速查表

摘自 `MPU-9250-Register-Map.pdf`。未列出的寄存器学习阶段可忽略。

### 4.1 配置与身份

| 地址 | 名称 | 复位 | 说明 |
|------|------|------|------|
| **0x19** | SMPLRT_DIV | 0x00 | 采样分频。开启 DLPF 时内部 1 kHz：`SampleRate = 1000 / (1 + DIV)` |
| **0x1A** | CONFIG | 0x00 | `[2:0] DLPF_CFG` 陀螺低通 |
| **0x1B** | GYRO_CONFIG | 0x00 | `[4:3] GYRO_FS_SEL` 量程 |
| **0x1C** | ACCEL_CONFIG | 0x00 | `[4:3] ACCEL_FS_SEL` 量程 |
| **0x1D** | ACCEL_CONFIG2 | 0x00 | 加计 DLPF |
| **0x37** | INT_PIN_CFG | 0x00 | `[1] BYPASS_EN` 旁路辅助 I2C |
| **0x38** | INT_ENABLE | 0x00 | `[0] RAW_RDY_EN` 数据就绪中断 |
| **0x3A** | INT_STATUS | 0x00 | `[0] RAW_DATA_RDY_INT` 读清 |
| **0x6A** | USER_CTRL | 0x00 | `[5] I2C_MST_EN`；旁路模式应保持 0 |
| **0x6B** | PWR_MGMT_1 | 0x01 | `[7] H_RESET`，`[6] SLEEP`，`[2:0] CLKSEL` |
| **0x6C** | PWR_MGMT_2 | 0x00 | 单独关闭某轴 |
| **0x75** | WHO_AM_I | **0x71** | 通信自检 |

### 4.2 传感器数据（一次连读）

从 **0x3B** 连续 14 字节：

| 地址 | 名称 |
|------|------|
| 0x3B–0x40 | ACCEL_X/Y/ZOUT_H/L |
| 0x41–0x42 | TEMP_OUT_H/L |
| 0x43–0x48 | GYRO_X/Y/ZOUT_H/L |

有符号 16 位，**高字节在前**。

### 4.3 量程与灵敏度

**陀螺 `GYRO_FS_SEL`：**

| FS_SEL | 量程 | 灵敏度 |
|--------|------|--------|
| 0 | ±250 °/s | **131** LSB/(°/s) |
| 1 | ±500 °/s | 65.5 |
| 2 | ±1000 °/s | 32.8 |
| 3 | ±2000 °/s | 16.4 |

**加计 `ACCEL_FS_SEL`：**

| FS_SEL | 量程 | 灵敏度 |
|--------|------|--------|
| 0 | ±2 g | **16384** LSB/g |
| 1 | ±4 g | 8192 |
| 2 | ±8 g | 4096 |
| 3 | ±16 g | 2048 |

飞控入门建议：**陀螺 ±2000 °/s、加计 ±8 g**（机动时不易饱和）。静止调试可用 ±250 °/s 和 ±2 g，分辨率更高。

### 4.4 温度换算

规格书：

```
Temp_degC = (TEMP_OUT - 21) / 333.87 + 21
```

## 5. 初始化流程

### 5.1 上电默认陷阱

复位后 `PWR_MGMT_1` 的 **SLEEP=1**，芯片在休眠，数据寄存器无有效输出。必须先唤醒。

### 5.2 推荐步骤

```
1. 延时 >= 100 ms（上电稳定）
2. 写 PWR_MGMT_1 = 0x80     // H_RESET
3. 延时 >= 100 ms
4. 读 WHO_AM_I，应为 0x71
5. 写 PWR_MGMT_1 = 0x01     // 清 SLEEP，CLKSEL=PLL（陀螺时钟）
6. 写 GYRO_CONFIG、ACCEL_CONFIG 设置量程
7. 写 CONFIG / SMPLRT_DIV   // 例如 1 kHz 采样、DLPF=41 Hz
8. （可选）INT_PIN_CFG 打开 BYPASS，再初始化 AK8963
9. 静置读若干组陀螺，求平均作为零偏
```

`CLKSEL=1` 使用陀螺 PLL，比内部 20 MHz 更稳，姿态积分更准。

### 5.3 与本工程的对应关系

`Modules/IMU/Src/imu.c` 里目前只探测 WHO_AM_I，尚未写配置。应把上述步骤放进 `IMU_Init()`，把周期读数放进 `IMU_Update()`（默认任务 1 ms 调用一次）。

## 6. 数据读取与单位换算

### 6.1 连读 14 字节

```c
uint8_t buf[14];
HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR << 1, 0x3B, 1, buf, 14, 100);

int16_t ax = (int16_t)((buf[0] << 8) | buf[1]);
int16_t ay = (int16_t)((buf[2] << 8) | buf[3]);
int16_t az = (int16_t)((buf[4] << 8) | buf[5]);
int16_t t  = (int16_t)((buf[6] << 8) | buf[7]);
int16_t gx = (int16_t)((buf[8] << 8) | buf[9]);
int16_t gy = (int16_t)((buf[10] << 8) | buf[11]);
int16_t gz = (int16_t)((buf[12] << 8) | buf[13]);
```

### 6.2 换成物理单位

```c
/* 以 ±8g、±2000 dps 为例 */
float ax_g   = ax / 4096.0f;
float gx_dps = (gx / 16.4f) - gyro_bias_x;   /* 减去上电零偏 */
```

`imu.h` 中 `Gyro_t` / `Accel_t` 建议约定：

- 加速度：g
- 角速度：°/s
- 姿态：度

### 6.3 陀螺零偏

上电后水平静置 200～500 次，对 gx/gy/gz 取平均，存为 bias。飞行中不要再清零。Z 轴仍会慢漂，航向要靠磁力计或光流修正。

## 7. 磁力计（AK8963）

AK8963 挂在 MPU 的 **辅助 I2C** 上，默认主机看不见。

### 7.1 打开旁路

`INT_PIN_CFG (0x37)` 的 **BYPASS_EN (bit1) = 1**，且 `USER_CTRL` 的 `I2C_MST_EN = 0`。之后主机可按地址 **0x0C** 访问 AK8963。

### 7.2 AK8963 关键寄存器

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x00 | WIA | 应为 **0x48** |
| 0x02 | ST1 | bit0=DRDY |
| 0x03–0x08 | HXL…HZH | 磁场，**低字节在前**（与 MPU 相反） |
| 0x09 | ST2 | **读完磁力数据后必须再读 ST2** |
| 0x0A | CNTL1 | MODE + BIT（14/16 bit） |
| 0x10–0x12 | ASAX/Y/Z | Fuse ROM 灵敏度 |

### 7.3 推荐初始化

```
1. CNTL1 = 0x00     Power-down
2. CNTL1 = 0x0F     Fuse ROM
3. 读 ASAX/ASAY/ASAZ
4. CNTL1 = 0x00     Power-down
5. CNTL1 = 0x16     连续测量 2 + 16-bit（100 Hz）
```

校正公式（手册）：

```
Hadj = H * ((ASA - 128) / 256 + 1)
```

14-bit 灵敏度约 **0.6 µT/LSB**。磁力计受电机电流干扰大，先把加计/陀螺跑通再加航向融合。

## 8. 姿态解算入门

`Control_Update()` 需要的是 `Attitude_t`（roll / pitch / yaw，单位建议为度）。

### 8.1 只用加速度（静态）

```c
roll  = atan2f(ay, az) * 57.29578f;
pitch = atan2f(-ax, sqrtf(ay*ay + az*az)) * 57.29578f;
```

机动时加速度 ≠ 重力，会严重不准。

### 8.2 互补滤波（建议先实现）

```
angle = α * (angle + gyro * dt) + (1-α) * acc_angle
```

`α` 约 0.96～0.98，`dt = 0.001`（与 1 ms 任务一致）。roll / pitch 用此法即可起飞调试；yaw 先用陀螺积分，接受慢漂。

### 8.3 下一步

稳定后再上 Mahony / Madgwick。DMP 固件闭源且占资源，本工程不推荐作为第一目标。

## 10. 完整代码示例

下面可直接填进现有 `imu.c` / `imu.h` 思路。量程：±8 g、±2000 °/s；地址 **0x69**。

### 10.1 读写与初始化要点

```c
#include "imu.h"
#include "i2c.h"
#include <stdio.h>
#include <math.h>

extern I2C_HandleTypeDef hi2c1;

#define MPU9250_ADDR        0x69
#define MPU9250_ADDR_HAL    (MPU9250_ADDR << 1)

#define REG_SMPLRT_DIV      0x19
#define REG_CONFIG          0x1A
#define REG_GYRO_CONFIG     0x1B
#define REG_ACCEL_CONFIG    0x1C
#define REG_INT_PIN_CFG     0x37
#define REG_ACCEL_XOUT_H    0x3B
#define REG_PWR_MGMT_1      0x6B
#define REG_WHO_AM_I        0x75

#define ACC_LSB_PER_G       4096.0f    /* ±8g */
#define GYRO_LSB_PER_DPS    16.4f      /* ±2000 dps */
#define RAD2DEG             57.2957795f

IMU_Data_t g_imuData;
static float gyro_bias[3];

static uint8_t MPU_Read(uint8_t reg)
{
    uint8_t v = 0;
    HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR_HAL, reg, 1, &v, 1, 100);
    return v;
}

static void MPU_Write(uint8_t reg, uint8_t val)
{
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR_HAL, reg, 1, &val, 1, 100);
}

static void Gyro_Calibrate(void)
{
    int32_t sx = 0, sy = 0, sz = 0;
    uint8_t buf[14];
    for (int i = 0; i < 200; i++) {
        HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR_HAL, REG_ACCEL_XOUT_H, 1, buf, 14, 100);
        sx += (int16_t)((buf[8] << 8) | buf[9]);
        sy += (int16_t)((buf[10] << 8) | buf[11]);
        sz += (int16_t)((buf[12] << 8) | buf[13]);
        HAL_Delay(2);
    }
    gyro_bias[0] = (sx / 200.0f) / GYRO_LSB_PER_DPS;
    gyro_bias[1] = (sy / 200.0f) / GYRO_LSB_PER_DPS;
    gyro_bias[2] = (sz / 200.0f) / GYRO_LSB_PER_DPS;
}

void IMU_Init(void)
{
    HAL_Delay(100);
    MPU_Write(REG_PWR_MGMT_1, 0x80);
    HAL_Delay(100);

    uint8_t id = MPU_Read(REG_WHO_AM_I);
    printf("MPU9250 WHO_AM_I=0x%02X (expect 0x71)\r\n", id);

    MPU_Write(REG_PWR_MGMT_1, 0x01);   /* 唤醒 + PLL */
    HAL_Delay(10);
    MPU_Write(REG_GYRO_CONFIG,  0x18); /* ±2000 dps */
    MPU_Write(REG_ACCEL_CONFIG, 0x10); /* ±8 g */
    MPU_Write(REG_CONFIG,       0x03); /* DLPF 41 Hz */
    MPU_Write(REG_SMPLRT_DIV,   0x00); /* 1 kHz */
    MPU_Write(REG_INT_PIN_CFG,  0x02); /* BYPASS_EN，可选 */

    Gyro_Calibrate();
}

void IMU_Update(void)
{
    uint8_t buf[14];
    const float dt = 0.001f;
    const float alpha = 0.98f;

    if (HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR_HAL, REG_ACCEL_XOUT_H,
                         1, buf, 14, 100) != HAL_OK)
        return;

    int16_t ax = (int16_t)((buf[0] << 8) | buf[1]);
    int16_t ay = (int16_t)((buf[2] << 8) | buf[3]);
    int16_t az = (int16_t)((buf[4] << 8) | buf[5]);
    int16_t gx = (int16_t)((buf[8] << 8) | buf[9]);
    int16_t gy = (int16_t)((buf[10] << 8) | buf[11]);
    int16_t gz = (int16_t)((buf[12] << 8) | buf[13]);

    float axg = ax / ACC_LSB_PER_G;
    float ayg = ay / ACC_LSB_PER_G;
    float azg = az / ACC_LSB_PER_G;
    float gxd = gx / GYRO_LSB_PER_DPS - gyro_bias[0];
    float gyd = gy / GYRO_LSB_PER_DPS - gyro_bias[1];
    float gzd = gz / GYRO_LSB_PER_DPS - gyro_bias[2];

    g_imuData.raw.accel.ax = axg;
    g_imuData.raw.accel.ay = ayg;
    g_imuData.raw.accel.az = azg;
    g_imuData.raw.gyro.gx  = gxd;
    g_imuData.raw.gyro.gy  = gyd;
    g_imuData.raw.gyro.gz  = gzd;

    float acc_roll  = atan2f(ayg, azg) * RAD2DEG;
    float acc_pitch = atan2f(-axg, sqrtf(ayg * ayg + azg * azg)) * RAD2DEG;

    g_imuData.attitude.roll  = alpha * (g_imuData.attitude.roll  + gxd * dt)
                             + (1.0f - alpha) * acc_roll;
    g_imuData.attitude.pitch = alpha * (g_imuData.attitude.pitch + gyd * dt)
                             + (1.0f - alpha) * acc_pitch;
    g_imuData.attitude.yaw  += gzd * dt;
}
```

`IMU_GetAttitude` / `IMU_GetGyro` / `IMU_GetAccel` 保持现有实现即可。

## 11. 常见问题

### 11.1 WHO_AM_I 不是 0x71

| 读数 | 含义 |
|------|------|
| 0x00 / 0xFF | I2C 失败：地址、上拉、nCS、焊盘、总线被 SPL06 拉死 |
| 0x68 也能 ACK 但 WHO 不对 | 试 0x68 / 0x69 两个地址 |
| 0x73 | MPU9255，寄存器大体兼容 |
| 0xEA | 贴的是 ICM-20948，驱动不能当 9250 用 |

本工程探测代码：`HAL_I2C_Mem_Read(&hi2c1, 0x69 << 1, 0x75, ...)`。

### 11.2 有 ACK，数据全 0

未清 `SLEEP`。确认 `PWR_MGMT_1` 写了 `0x01` 且延时足够。

### 11.3 水平放置 az 不是 ±1 g

量程宏与 `ACCEL_CONFIG` 不一致，或轴映射/安装方向反了。先打印原始 int16，再对灵敏度。

### 11.4 姿态飘、PID 反了

- 陀螺没减零偏
- `dt` 与任务周期不符
- 机体坐标与电机混控（`control.c` 的 X 型）不一致 → **先手动模式看数，再开 AUTO**

### 11.5 读磁力计 NACK

未置 `BYPASS_EN`，或 `I2C_MST_EN` 仍为 1。WIA 应为 `0x48`。读完 Hxxx **必须读 ST2**。

### 11.6 I2C 卡死

400 kHz 下接触不良容易把总线拉死。可在超时后：

```c
HAL_I2C_DeInit(&hi2c1);
MX_I2C1_Init();
```

与 SPL06 同总线时，不要在两个任务里同时访问 I2C1。

## 学习路径建议

1. 读通 WHO_AM_I = `0x71`
2. 打印加速度，确认重力轴
3. 标定陀螺零偏，看角速度近 0
4. 互补滤波得到 roll / pitch
5. 手动模式摇飞机，确认符号再开 PID
6. 再加 AK8963 与 yaw
