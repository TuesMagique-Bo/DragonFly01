## 1. MPU9250 简介

MPU9250 是 InvenSense 公司推出的 **9 轴运动跟踪传感器**，内部集成：

| 传感器 | 轴数 | 分辨率 | 量程 |
|--------|------|--------|------|
| 陀螺仪 | 3 轴 | 16 bit | ±250/±500/±1000/±2000 °/s |
| 加速度计 | 3 轴 | 16 bit | ±2/±4/±8/±16 g |
| 磁力计 (AK8963) | 3 轴 | 14/16 bit | ±4800 µT |

**关键特性：**
- 通信接口：I2C（最高 400kHz）或 SPI
- 内置 512 字节 FIFO
- 可编程数字低通滤波器（DLPF）
- 支持 Wake-on-Motion 低功耗模式
- 内置温度传感器
- 工作电压：VDD 2.4~3.6V，VDDIO 1.71V~VDD

## 2. DragonFly V2 硬件连接

### 2.1 引脚连接

```
STM32F411CEU6          MPU9250 (U9)
─────────────          ─────────────
PB6 (I2C1_SCL) ────── Pin 23 (SCL)
PB7 (I2C1_SDA) ────── Pin 24 (SDA)
PB2 (IMU_INT)  ────── Pin 12 (INT1)
3V3             ────── Pin 13 (VDD)
3V3 (经FB3)     ────── Pin 8  (VDDIO)
GND             ────── Pin 18 (GND)
```

### 2.2 I2C 地址

| AD0 引脚 | 7-bit 地址 | 8-bit 写地址 | 8-bit 读地址 |
|----------|-----------|-------------|-------------|
| **AD0 = 1** (本板) | **0x69** | 0xD2 | 0xD3 |

> 本板通过 R34（0Ω）将 AD0 上拉到 3V3，地址为 **0x69**。

### 2.3 I2C 上拉电阻

- R22: 10KΩ（SCL → 3V3）
- R23: 10KΩ（SDA → 3V3）

### 2.4 共享总线设备

I2C1 总线同时挂载：
- **MPU9250**（地址 0x69）
- **SPL06 气压计**（地址 0x76 或 0x77）

## 3. I2C 通信基础

### 3.1 写寄存器

```
START | SLAVE_ADDR(W) | REG_ADDR | DATA | STOP
  │         │             │         │       │
  └─ 起始   └─ 0xD2       └─ 寄存器  └─ 数据  └─ 停止
```

### 3.2 读寄存器

```
START | SLAVE_ADDR(W) | REG_ADDR | RESTART | SLAVE_ADDR(R) | DATA[0..N] | STOP
```

### 3.3 HAL 库操作示例

```c
// 写单个寄存器
uint8_t data = 0x01;
HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR, REG_ADDR, 1, &data, 1, 100);

// 读多个寄存器
uint8_t buf[6];
HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR, REG_ADDR, 1, buf, 6, 100);
```

## 4. 寄存器速查表

### 4.1 核心配置寄存器

| 地址 | 名称 | 功能 | 关键位 |
|------|------|------|--------|
| **0x75** | WHO_AM_I | 设备 ID（固定 0x71） | [7:0] |
| **0x6B** | PWR_MGMT_1 | 电源管理 | [7]H_RESET, [6]SLEEP, [2:0]CLKSEL |
| **0x6C** | PWR_MGMT_2 | 传感器使能 | [5:3] 禁用加速度计, [2:0] 禁用陀螺仪 |
| **0x1A** | CONFIG | DLPF 配置 | [2:0]DLPF_CFG |
| **0x1B** | GYRO_CONFIG | 陀螺仪配置 | [4:3]FS_SEL, [1:0]FCHOICE_B |
| **0x1C** | ACCEL_CONFIG | 加速度计配置 | [4:3]FS_SEL |
| **0x1D** | ACCEL_CONFIG2 | 加速度计 DLPF | [3]FCHOICE_B, [2:0]A_DLPF_CFG |
| **0x19** | SMPLRT_DIV | 采样率分频 | [7:0] |
| **0x37** | INT_PIN_CFG | 中断引脚配置 | [1]BYPASS_EN |
| **0x38** | INT_ENABLE | 中断使能 | [0]RAW_RDY_EN |
| **0x6A** | USER_CTRL | 用户控制 | [6]FIFO_EN, [5]I2C_MST_EN |

### 4.2 数据寄存器（连续 14 字节）

| 地址 | 名称 | 内容 |
|------|------|------|
| 0x3B | ACCEL_XOUT_H | 加速度 X 高字节 |
| 0x3C | ACCEL_XOUT_L | 加速度 X 低字节 |
| 0x3D | ACCEL_YOUT_H | 加速度 Y 高字节 |
| 0x3E | ACCEL_YOUT_L | 加速度 Y 低字节 |
| 0x3F | ACCEL_ZOUT_H | 加速度 Z 高字节 |
| 0x40 | ACCEL_ZOUT_L | 加速度 Z 低字节 |
| 0x41 | TEMP_OUT_H | 温度高字节 |
| 0x42 | TEMP_OUT_L | 温度低字节 |
| 0x43 | GYRO_XOUT_H | 陀螺仪 X 高字节 |
| 0x44 | GYRO_XOUT_L | 陀螺仪 X 低字节 |
| 0x45 | GYRO_YOUT_H | 陀螺仪 Y 高字节 |
| 0x46 | GYRO_YOUT_L | 陀螺仪 Y 低字节 |
| 0x47 | GYRO_ZOUT_H | 陀螺仪 Z 高字节 |
| 0x48 | GYRO_ZOUT_L | 陀螺仪 Z 低字节 |

> 可以从 0x3B 开始连续读取 14 字节，一次性获取全部数据。

### 4.3 陀螺仪量程配置

| FS_SEL[1:0] | 量程 (°/s) | 灵敏度 (LSB/(°/s)) |
|-------------|-----------|---------------------|
| 00 | ±250 | 131.0 |
| 01 | ±500 | 65.5 |
| 10 | ±1000 | 32.8 |
| 11 | ±2000 | 16.4 |

### 4.4 加速度计量程配置

| AFS_SEL[1:0] | 量程 (g) | 灵敏度 (LSB/g) |
|-------------|---------|-----------------|
| 00 | ±2 | 16384 |
| 01 | ±4 | 8192 |
| 10 | ±8 | 4096 |
| 11 | ±16 | 2048 |

### 4.5 陀螺仪 DLPF 配置（CONFIG, 0x1A）

| DLPF_CFG | 带宽 (Hz) | 延迟 (ms) | 采样率 (kHz) |
|----------|----------|----------|-------------|
| 0 | 250 | 0.97 | 8 |
| 1 | 184 | 2.9 | 1 |
| 2 | 92 | 3.9 | 1 |
| 3 | 41 | 5.9 | 1 |
| 4 | 20 | 9.9 | 1 |
| 5 | 10 | 17.85 | 1 |
| 6 | 5 | 33.48 | 1 |

> 飞控常用：DLPF_CFG = 2（92Hz 带宽，平衡延迟和噪声）

### 4.6 时钟源选择（PWR_MGMT_1, CLKSEL[2:0]）

| CLKSEL | 时钟源 |
|--------|--------|
| 0 | 内部 20MHz 振荡器 |
| **1** | **自动选择（PLL 优先）← 推荐** |
| 2~5 | 自动选择（PLL 优先） |
| 6 | 内部 20MHz 振荡器 |
| 7 | 停止时钟 |

## 5. 初始化流程

### 5.1 标准初始化步骤

```
1. 验证 WHO_AM_I（0x75）== 0x71
2. 复位设备：PWR_MGMT_1[7] = 1，等待 100ms
3. 唤醒并设置时钟：PWR_MGMT_1 = 0x01（CLKSEL=1, 自动 PLL）
4. 等待 PLL 稳定：延时 50ms
5. 配置陀螺仪：GYRO_CONFIG（量程 + DLPF）
6. 配置加速度计：ACCEL_CONFIG（量程）+ ACCEL_CONFIG2（DLPF）
7. 配置采样率：SMPLRT_DIV
8. 配置中断：INT_PIN_CFG（BYPASS_EN）+ INT_ENABLE
9. 初始化 AK8963 磁力计
```

### 5.2 初始化代码

```c
#define MPU9250_ADDR      0x69   // AD0 = 1
#define MPU9250_WHO_AM_I  0x75
#define MPU9250_PWR_MGMT1 0x6B
#define MPU9250_GYRO_CFG  0x1B
#define MPU9250_ACCEL_CFG 0x1C
#define MPU9250_ACCEL_CFG2 0x1D
#define MPU9250_CONFIG    0x1A
#define MPU9250_SMPLRT_DIV 0x19
#define MPU9250_INT_PIN_CFG 0x37
#define MPU9250_INT_ENABLE  0x38
#define MPU9250_USER_CTRL   0x6A

uint8_t MPU9250_Init(void)
{
    uint8_t whoami;

    /* 1. 验证设备 ID */
    HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR << 1, MPU9250_WHO_AM_I,
                     1, &whoami, 1, 100);
    if (whoami != 0x71) {
        printf("MPU9250 WHO_AM_I error: 0x%02X\r\n", whoami);
        return 0;
    }

    /* 2. 复位设备 */
    uint8_t reset = 0x80;  // H_RESET = 1
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_PWR_MGMT1,
                      1, &reset, 1, 100);
    HAL_Delay(100);

    /* 3. 唤醒并设置时钟源为自动 PLL */
    uint8_t clk = 0x01;  // CLKSEL = 1 (Auto PLL), SLEEP = 0
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_PWR_MGMT1,
                      1, &clk, 1, 100);
    HAL_Delay(50);

    /* 4. 配置陀螺仪：±2000°/s, FCHOICE_B=00 使能 DLPF */
    uint8_t gyro_cfg = (3 << 3);  // FS_SEL = 11 (2000dps)
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_GYRO_CFG,
                      1, &gyro_cfg, 1, 100);

    /* 5. 配置加速度计：±16g */
    uint8_t accel_cfg = (3 << 3);  // AFS_SEL = 11 (16g)
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_ACCEL_CFG,
                      1, &accel_cfg, 1, 100);

    /* 6. 加速度计 DLPF：带宽 41Hz */
    uint8_t accel2_cfg = 0x03;  // FCHOICE_B=0, A_DLPF_CFG=3
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_ACCEL_CFG2,
                      1, &accel2_cfg, 1, 100);

    /* 7. 陀螺仪 DLPF：带宽 41Hz */
    uint8_t dlpf_cfg = 0x03;  // DLPF_CFG = 3
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_CONFIG,
                      1, &dlpf_cfg, 1, 100);

    /* 8. 采样率：1kHz / (1+0) = 1kHz */
    uint8_t smplrt = 0x00;
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_SMPLRT_DIV,
                      1, &smplrt, 1, 100);

    /* 9. 使能 I2C 旁路（直通 AK8963） */
    uint8_t int_cfg = 0x02;  // BYPASS_EN = 1
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_INT_PIN_CFG,
                      1, &int_cfg, 1, 100);

    /* 10. 使能数据就绪中断 */
    uint8_t int_en = 0x01;  // RAW_RDY_EN = 1
    HAL_I2C_Mem_Write(&hi2c1, MPU9250_ADDR << 1, MPU9250_INT_ENABLE,
                      1, &int_en, 1, 100);

    printf("MPU9250 init OK\r\n");
    return 1;
}
```

## 6. 读取传感器数据

### 6.1 数据格式

所有传感器数据均为 **16 位有符号整数（二进制补码）**，**高字节在前（Big Endian）**。

```c
/* 组合两个字节为 int16_t */
#define COMBINE_HL(h, l)  ((int16_t)((h << 8) | l))
```

### 6.2 读取加速度计和陀螺仪

```c
void MPU9250_ReadAccelGyro(int16_t *accel, int16_t *gyro)
{
    uint8_t buf[14];

    /* 从 0x3B 开始连续读 14 字节 */
    HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR << 1, 0x3B,
                     1, buf, 14, 100);

    accel[0] = COMBINE_HL(buf[0], buf[1]);   // AX
    accel[1] = COMBINE_HL(buf[2], buf[3]);   // AY
    accel[2] = COMBINE_HL(buf[4], buf[5]);   // AZ
    /* buf[6:7] = 温度（跳过） */
    gyro[0]  = COMBINE_HL(buf[8], buf[9]);   // GX
    gyro[1]  = COMBINE_HL(buf[10], buf[11]); // GY
    gyro[2]  = COMBINE_HL(buf[12], buf[13]); // GZ
}
```

### 6.3 转换为物理单位

```c
/* 加速度计：±16g → 2048 LSB/g */
float accel_g[3];
accel_g[0] = raw_accel[0] / 2048.0f;
accel_g[1] = raw_accel[1] / 2048.0f;
accel_g[2] = raw_accel[2] / 2048.0f;

/* 陀螺仪：±2000°/s → 16.4 LSB/(°/s) */
float gyro_dps[3];
gyro_dps[0] = raw_gyro[0] / 16.4f;
gyro_dps[1] = raw_gyro[1] / 16.4f;
gyro_dps[2] = raw_gyro[2] / 16.4f;
```

### 6.4 读取温度

```c
float MPU9250_ReadTemp(void)
{
    uint8_t buf[2];
    HAL_I2C_Mem_Read(&hi2c1, MPU9250_ADDR << 1, 0x41,
                     1, buf, 2, 100);
    int16_t raw = COMBINE_HL(buf[0], buf[1]);
    return (raw / 333.87f) + 21.0f;
}
```

## 7. AK8963 磁力计操作

### 7.1 访问方式

MPU9250 内部集成了 AK8963 磁力计芯片，通过 **I2C 辅助总线**连接。有两种访问方式：

| 方式 | 说明 | 复杂度 |
|------|------|--------|
| **I2C 旁路模式** | 设置 BYPASS_EN=1，MPU9250 将 SDA/SCL 直通给 AK8963 | **低（推荐）** |
| I2C Master 模式 | MPU9250 作为 I2C 主机读取 AK8963 数据存入 EXT_SENS_DATA 寄存器 | 高 |

> 本教程使用 **旁路模式**，简单直接。

### 7.2 AK8963 寄存器

| 地址 | 名称 | 说明 |
|------|------|------|
| 0x00 | WIA | 设备 ID（固定 **0x48**） |
| 0x02 | ST1 | 状态 1：[0]DRDY |
| 0x03 | HXL | X 轴低字节 |
| 0x04 | HXH | X 轴高字节 |
| 0x05 | HYL | Y 轴低字节 |
| 0x06 | HYH | Y 轴高字节 |
| 0x07 | HZL | Z 轴低字节 |
| 0x08 | HZH | Z 轴高字节 |
| 0x09 | ST2 | 状态 2 |
| 0x0A | CNTL1 | 控制 1：[3:0]MODE |
| 0x0B | CNTL2 | 控制 2：[0]SRST（软复位） |
| 0x10 | ASAX | X 轴灵敏度校准 |
| 0x11 | ASAY | Y 轴灵敏度校准 |
| 0x12 | ASAZ | Z 轴灵敏度校准 |

### 7.3 AK8963 工作模式

| MODE[3:0] | 模式 |
|-----------|------|
| 0000 | 掉电 |
| 0001 | 单次测量 |
| **0010** | **连续测量 1（8Hz）← 常用** |
| 0110 | 连续测量 2（100Hz） |
| 1111 | Fuse ROM 访问（读取校准值） |

### 7.4 AK8963 初始化

```c
#define AK8963_ADDR    0x0C   // 磁力计 I2C 地址（固定）
#define AK8963_WIA     0x00
#define AK8963_CNTL1   0x0A
#define AK8963_ASAX    0x10

/* 磁力计灵敏度校准值（从 Fuse ROM 读取） */
static float mag_cal[3] = {1.0f, 1.0f, 1.0f};

uint8_t AK8963_Init(void)
{
    uint8_t whoami;

    /* 前提：MPU9250 已设置 BYPASS_EN = 1 */

    /* 1. 验证设备 ID */
    HAL_I2C_Mem_Read(&hi2c1, AK8963_ADDR << 1, AK8963_WIA,
                     1, &whoami, 1, 100);
    if (whoami != 0x48) {
        printf("AK8963 WHO_AM_I error: 0x%02X\r\n", whoami);
        return 0;
    }

    /* 2. 软复位 */
    uint8_t rst = 0x01;
    HAL_I2C_Mem_Write(&hi2c1, AK8963_ADDR << 1, 0x0B,
                      1, &rst, 1, 100);
    HAL_Delay(10);

    /* 3. 读取 Fuse ROM 校准值 */
    AK8963_ReadCalibration();

    /* 4. 设置为连续测量模式 1（8Hz） */
    uint8_t mode = 0x02;  // MODE = 0010
    HAL_I2C_Mem_Write(&hi2c1, AK8963_ADDR << 1, AK8963_CNTL1,
                      1, &mode, 1, 100);
    HAL_Delay(10);

    printf("AK8963 init OK\r\n");
    return 1;
}
```

### 7.5 读取磁力计数据

```c
void AK8963_ReadMag(int16_t *mag)
{
    uint8_t buf[7];  // ST1 + HXL/H + HYL/H + HZL/H + ST2

    HAL_I2C_Mem_Read(&hi2c1, AK8963_ADDR << 1, 0x02,
                     1, buf, 7, 100);

    /* 检查 DRDY 位 */
    if (!(buf[0] & 0x01)) return;  // 数据未就绪

    /* 检查磁力传感器溢出 */
    if (buf[6] & 0x08) return;     // HOFL

    mag[0] = COMBINE_HL(buf[2], buf[1]);  // X
    mag[1] = COMBINE_HL(buf[4], buf[3]);  // Y
    mag[2] = COMBINE_HL(buf[6], buf[5]);  // Z

    /* 应用灵敏度校准 */
    // mag[0] *= mag_cal[0];
    // mag[1] *= mag_cal[1];
    // mag[2] *= mag_cal[2];
}
```

### 7.6 读取 Fuse ROM 校准值

```c
void AK8963_ReadCalibration(void)
{
    uint8_t buf[3];

    /* 切换到 Fuse ROM 访问模式 */
    uint8_t mode = 0x0F;  // MODE = 1111
    HAL_I2C_Mem_Write(&hi2c1, AK8963_ADDR << 1, AK8963_CNTL1,
                      1, &mode, 1, 100);
    HAL_Delay(10);

    /* 读取 ASAX, ASAY, ASAZ */
    HAL_I2C_Mem_Read(&hi2c1, AK8963_ADDR << 1, AK8963_ASAX,
                     1, buf, 3, 100);

    /* 换算公式：Hadj = H × (((ASA - 128) × 0.5) / 128 + 1) */
    for (int i = 0; i < 3; i++) {
        mag_cal[i] = (((float)buf[i] - 128.0f) * 0.5f) / 128.0f + 1.0f;
    }

    /* 切回掉电模式 */
    mode = 0x00;
    HAL_I2C_Mem_Write(&hi2c1, AK8963_ADDR << 1, AK8963_CNTL1,
                      1, &mode, 1, 100);
    HAL_Delay(10);
}
```

## 8. 完整代码示例

### 8.1 MPU9250 头文件 (`mpu9250.h`)

```c
#ifndef __MPU9250_H__
#define __MPU9250_H__

#include "main.h"
#include "i2c.h"

/* MPU9250 I2C 地址 */
#define MPU9250_ADDR      0x69

/* AK8963 磁力计 I2C 地址 */
#define AK8963_ADDR       0x0C

/* 传感器数据结构体 */
typedef struct {
    int16_t accel[3];   // X, Y, Z 原始值
    int16_t gyro[3];    // X, Y, Z 原始值
    int16_t mag[3];     // X, Y, Z 原始值
    float   temp;       // 温度 (°C)
} MPU9250_Data_t;

/* 函数声明 */
uint8_t MPU9250_Init(void);
uint8_t AK8963_Init(void);
void    MPU9250_ReadAll(MPU9250_Data_t *data);
void    MPU9250_ReadAccelGyro(int16_t *accel, int16_t *gyro);
void    AK8963_ReadMag(int16_t *mag);
float   MPU9250_ReadTemp(void);

#endif /* __MPU9250_H__ */
```

### 8.2 一次性读取全部 9 轴数据

```c
void MPU9250_ReadAll(MPU9250_Data_t *data)
{
    MPU9250_ReadAccelGyro(data->accel, data->gyro);
    AK8963_ReadMag(data->mag);
    data->temp = MPU9250_ReadTemp();
}
```

### 8.3 集成到 FreeRTOS 任务

```c
void IMU_Task(void const *argument)
{
    MPU9250_Data_t imu;

    if (!MPU9250_Init()) {
        printf("MPU9250 init failed!\r\n");
        while (1);
    }
    if (!AK8963_Init()) {
        printf("AK8963 init failed!\r\n");
        while (1);
    }

    for (;;) {
        MPU9250_ReadAll(&imu);

        /* 转换为物理单位 */
        float ax = imu.accel[0] / 2048.0f;  // 16g → 2048 LSB/g
        float ay = imu.accel[1] / 2048.0f;
        float az = imu.accel[2] / 2048.0f;
        float gx = imu.gyro[0]  / 16.4f;   // 2000dps → 16.4 LSB/(°/s)
        float gy = imu.gyro[1]  / 16.4f;
        float gz = imu.gyro[2]  / 16.4f;

        // 姿态解算、PID 控制等...

        osDelay(1);  // 1ms 周期 = 1kHz
    }
}
```

## 9. 校准与数据处理

### 9.1 陀螺仪零偏校准

静止状态下读取 N 次陀螺仪数据，取平均值作为零偏：

```c
#define CALIB_SAMPLES  2000

void MPU9250_CalibrateGyro(float *bias)
{
    int32_t sum[3] = {0};

    for (int i = 0; i < CALIB_SAMPLES; i++) {
        int16_t raw[3], dummy[3];
        MPU9250_ReadAccelGyro(dummy, raw);
        sum[0] += raw[0];
        sum[1] += raw[1];
        sum[2] += raw[2];
        osDelay(1);
    }

    bias[0] = (float)sum[0] / CALIB_SAMPLES / 16.4f;  // 转换为 °/s
    bias[1] = (float)sum[1] / CALIB_SAMPLES / 16.4f;
    bias[2] = (float)sum[2] / CALIB_SAMPLES / 16.4f;
}
```

使用时从原始值中减去零偏：
```c
gyro_dps[0] = raw_gyro[0] / 16.4f - bias[0];
gyro_dps[1] = raw_gyro[1] / 16.4f - bias[1];
gyro_dps[2] = raw_gyro[2] / 16.4f - bias[2];
```

### 9.2 加速度计校准（6 面校准法）

将飞控板依次 6 个面朝上放置，记录每个面的加速度值，计算偏移和比例因子。

### 9.3 磁力计校准（椭球拟合）

磁力计受硬铁和软铁干扰，需要椭球拟合校准。常见方法：
- 绕设备 8 字形旋转，采集数据
- 用椭球拟合算法（如磁力计校准工具）计算偏移和比例因子

### 9.4 低通滤波

```c
/* 一阶低通滤波器 */
float LPF_Apply(float input, float *state, float alpha)
{
    *state = alpha * input + (1.0f - alpha) * (*state);
    return *state;
}

/* 使用示例：alpha=0.1 对应约 10Hz 截止频率 */
static float accel_filt[3] = {0};
accel_filt[0] = LPF_Apply(raw_accel[0], &accel_filt[0], 0.1f);
```

## 10. 常见问题

### Q1: WHO_AM_I 读出来是 0xFF 或 0x00？

- 检查 I2C 接线（SCL/SDA 是否接反）
- 检查上拉电阻是否焊接（R22、R23 应为 10KΩ）
- 检查 I2C 地址是否正确（本板 AD0=1，地址 0x69）
- 用示波器/逻辑分析仪抓 I2C 波形，确认 ACK 位

### Q2: 数据一直为 0？

- 确认 PWR_MGMT_1 的 SLEEP 位 = 0（已唤醒）
- 确认 CLKSEL 不是 7（停止时钟）
- 确认 PWR_MGMT_2 中对应传感器未禁用

### Q3: AK8963 读取失败？

- 确认 INT_PIN_CFG 的 BYPASS_EN 位 = 1
- 确认 AK8963 的 CNTL1 设置为连续测量模式
- AK8963 最大输出速率 100Hz，不要超过

### Q4: 陀螺仪数据漂移严重？

- 首次上电后需要等待温度稳定（约 1-2 分钟）
- 使用前进行零偏校准
- 确保 DLPF 带宽设置合理（飞控推荐 41-92Hz）

### Q5: 数据噪声大？

- 减小 DLPF 带宽（更大的 DLPF_CFG 值）
- 检查电源去耦电容是否正常
- 电机 PWM 干扰：飞控板布局应远离电机驱动线路
